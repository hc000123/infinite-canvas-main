# 模型渠道厂商整包预设设计

## 目标

把后台模型渠道从“逐字段、逐模型、逐渠道配置”收口为“选择厂商、填写凭证、一次应用”。预设负责协议、接口地址、模型列表、能力、环境和运行参数；管理员只填写该厂商无法内置的凭证或接入点信息。

本功能只简化渠道配置，不改变模型运行时路由规则：模型仍按后台渠道映射选择协议，API Key 仍只保存在后端私有设置中。

## 方案选择

采用“厂商整包预设”，不采用单渠道自动填表，也不新增后端动态预设中心。

- 单渠道自动填表无法解决同一中转站内文本、图片、视频模型能力混用的问题。
- 后端动态预设中心需要新增预设表、管理接口和版本同步，当前阶段收益不足。
- 前端静态整包预设可以复用现有设置保存接口，并用纯函数保证批量更新可测试、可预览、可重复执行。

## 用户界面

在后台“模型渠道”区域增加“一键配置厂商”入口。点击后打开与现有后台主题一致的 Ant Design 弹窗：

1. 顶部展示厂商预设卡片：火山 Ark、星链云、即梦 CLI、Comfly、通用 OpenAI 兼容。
2. 选择厂商后，只显示该预设必需的输入项。
3. 下方展示变更预览：将新增、更新、停用的渠道，以及将开放的模型数量。
4. 点击“一次配置”后，通过现有设置接口原子保存全部渠道和公开模型目录。
5. 保存成功后刷新渠道表；保存失败时不修改页面当前设置。

不增加新的独立设置页面，不改变现有单渠道编辑抽屉。高级用户仍可在应用预设后编辑单个渠道。

## 预设目录

### 火山 Ark / Seedance

- 固定协议：`volcengine-ark`
- 固定地址：`https://ark.cn-beijing.volces.com/api/v3`
- 固定渠道 ID：`volcengine-seedance`
- 固定模型：`doubao-seedance-2-0`
- 固定能力：`video`、`video_query`、`asset_review`、`preflight`
- 固定环境：`prod`
- 必填：API Key、Endpoint / EP
- 本地模型到 EP 的映射由预设自动生成。

### 星链云 SD2

- 固定协议：`xinglian-cloud`
- 固定地址：`https://www.vjimeng.vip/v1`
- 固定渠道 ID：`xinglian-cloud`
- 固定能力：`video`、`video_query`、`preflight`
- 固定环境：`prod`
- 必填：API Key
- 自动开放模型：
  - `sd2-720p-fast`
  - `sd2-720p`
  - `sd2-720p-sh`
  - `sd2-720p-mini`
  - `sd2-1080p-mini`
  - `sd2-1080p-fast`
  - `sd2-1080p`
  - `sd2-720p-ax-fast`
  - `sd2-720p-ax`

### 即梦 CLI / Seedance

- 固定协议：`jimeng-cli`
- 固定渠道 ID：`jimeng-video`
- 固定能力：`video`、`video_query`、`preflight`、`cli_workflow`
- 固定环境：`prod`
- 默认并发：`1`
- 自动开放模型：`seedance2.0mini`、`seedance2.0fast`、`seedance2.0`、`seedance2.0_vip`、`seedance2.0fast_vip`
- 不填写 API Key；应用预设后继续使用现有即梦网页授权入口。
- 已有 CLI 路径、工作目录、输出目录、会话 ID 和超时设置保持不变；新渠道使用项目默认值。

### Comfly 中转

同一个 API Key 一次生成三个独立渠道，避免所有模型共享同一能力标签：

- `comfly-text`：`gpt-5.5-pro`、`gpt-5.5`、`gemini-3.1-pro-preview`，能力为 `text`。
- `comfly-image`：`gemini-3.1-flash-image-preview`、`nano-banana-pro`、`nano-banana-2`、`nano-banana-pro-2k`、`gpt-image-2-all`，能力为 `image`。
- `comfly-video`：`veo3.1-fast`、`veo3.1`，能力为 `video`、`video_query`。

三个渠道固定使用 `openai` 协议、`https://ai.comfly.org` 地址和 `prod` 环境。必填项只有 API Key。

如果存在旧 `comfly` 混合渠道，应用预设时复用其已保存 Key，并将旧渠道停用；不会删除旧记录，也不会产生重复路由。

### 通用 OpenAI 兼容

通用中转无法预知域名、模型和能力，因此只自动设置通用结构。管理员填写：

- 渠道名称
- Base URL
- API Key
- 渠道能力（文本、图片或视频）

模型列表可调用现有“读取模型”能力后批量选择。该预设不根据模型名猜测能力。

## 数据结构与代码边界

新增独立纯函数模块 `web/src/app/(admin)/admin/settings/model-channel-presets.ts`，包含：

- 预设 ID、名称、说明和凭证字段定义。
- 单渠道或多渠道模板。
- `applyModelChannelPreset`：接收当前设置、预设和凭证，返回下一份完整设置及变更摘要。

设置页面只负责表单、预览、调用纯函数和保存，不在 JSX 中堆叠厂商规则。后端继续使用现有 `SaveSettings` 校验协议冲突、渠道规范化和密钥保留逻辑。

## 重复应用与覆盖规则

预设应用必须幂等：同一预设重复应用不会增加重复渠道。

- 以稳定渠道 ID 更新已有渠道。
- 协议、标准地址、模型、能力和环境按当前预设更新。
- 新输入的密钥覆盖旧密钥；输入留空时保留已保存密钥。
- 火山 EP 留空时保留已有映射；首次配置时必须填写。
- 即梦运行目录、CLI 路径、会话和超时等高级字段优先保留已有值。
- Comfly 可从旧 `comfly` 渠道继承 API Key，并停用旧混合渠道。
- 自动把预设模型加入公开模型目录，同时清理已不属于任何启用渠道的陈旧模型。
- 不修改默认文本、图片和视频模型；如果默认模型已经失效，继续交给现有设置规范化逻辑处理。
- 不自动生成或猜测 `modelCosts`；已有费用配置按模型名保留。

## 凭证安全

- API Key 不进入预设常量、变更摘要、日志或公开设置。
- 编辑已有预设时只显示“已保存”状态，不回显明文。
- 前端输入为空表示保留后台密钥，不使用空字符串覆盖。
- 通用 OpenAI 兼容地址继续由现有后端和代理边界校验。

## 错误处理

- 首次应用缺少必填凭证时在本地阻止保存，并定位到缺失字段。
- 火山首次应用缺少 EP 时阻止保存。
- 预设模型与其他协议已有模型冲突时，展示现有后端冲突信息，不静默改写其他渠道。
- 保存请求失败时保留弹窗输入和变更预览，允许重试。
- 应用成功后再关闭弹窗并刷新渠道列表。

## 测试方案

### 纯函数测试

- 星链云预设一次生成九个模型，重复应用不增加渠道。
- 火山预设正确生成本地模型到 EP 映射，留空 EP 时保留旧值。
- 即梦预设保留已有 CLI 高级设置。
- Comfly 一次拆出三个能力互不混用的渠道，并停用旧混合渠道。
- 密钥留空时保留已有值，新密钥会覆盖。
- 公开模型目录自动加入新模型、移除无启用渠道的陈旧模型。
- 费用配置和默认模型保持不变。

### 页面测试

- 预设入口、厂商选择、动态凭证字段和变更摘要可见。
- 缺少必填字段不能提交。
- 保存成功刷新渠道表，保存失败保留表单。

### 回归验证

- 现有单渠道新建、编辑、测试和删除流程不变。
- `/api/settings` 只公开模型来源，不包含密钥或私有地址。
- 全量前端测试、TypeScript、Next 生产构建、Go 测试和 Docker 健康检查通过。

## 验收标准

1. 星链云只填写一次 API Key，即可得到九个已开放视频模型。
2. 火山只填写 API Key 和 EP，即可得到可调用的 Seedance 模型映射。
3. 即梦不填写接口地址或 Key，即可创建五模型渠道并继续网页授权。
4. Comfly 只填写一次 Key，即可得到文本、图片、视频三个渠道，模型不会跨能力显示。
5. 重复应用任一预设不产生重复渠道或重复模型。
6. 已保存密钥不会在页面、公开接口或日志中回显。
7. 应用预设不会擅自改变默认模型或覆盖已有费用。
