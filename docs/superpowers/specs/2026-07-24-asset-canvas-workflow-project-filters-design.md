# 素材库画布与工作流项目筛选设计

## 目标

在素材库顶部提供清晰、可扩展的项目筛选，让用户可以按“工作流项目”或“画布”快速定位素材，同时保持现有界面的低视觉重量，并继续与类型、收藏、关键词和名称排序组合使用。

## 现状

- 当前“项目”行只展示带项目文件夹的工作流项目。
- 画布筛选字段已经存在，但页面状态固定为空，界面没有入口。
- 画布相关素材有两类关联：由画布节点生成的素材，以及手动加入某个画布素材库的素材。
- 直接把所有工作流项目和画布平铺成标签，在项目数量增加后会显著占用纵向空间。

## 交互设计

“项目”筛选行调整为三个紧凑入口：

1. `全部项目`：清除工作流项目、画布及其依赖筛选。
2. `工作流项目`：可搜索下拉框，显示现有工作流项目。
3. `画布`：可搜索下拉框，显示现有画布名称。

工作流项目与画布采用互斥选择：

- 选择工作流项目时清除画布筛选，并保持现有项目文件夹、集数、分镜组、项目库和引用版本联动。
- 选择画布时清除工作流项目及其依赖筛选，文件夹回到“全部”。
- 点击“全部项目”同时清除两类项目筛选。

下拉框允许搜索，宽度随窄屏换行，不展开永久标签列表。选中值直接显示项目或画布名称。

## 数据匹配

### 工作流项目

沿用现有工作流项目与项目文件夹的映射。选择工作流项目时，同时选中其项目文件夹，因此当前项目内的素材、集数和分镜联动行为不变。

### 画布

一个素材满足下列任一条件时，视为属于所选画布：

- 素材的 `metadata.canvasLibraries` 包含该画布 ID；
- 素材任一生成记录的 `canvasId` 等于该画布 ID；
- 素材生成记录使用旧结构，且画布 ID 记录在 `projectId`，同时生成来源为画布。

匹配逻辑集中在素材库的纯函数工具中，页面只管理筛选状态，不在组件内解析元数据。

## 状态与数据流

- `useAssetPageQuery` 将当前固定的 `canvasLibraryFilter` 改为可更新状态，并生成工作流项目、画布下拉选项。
- `useAssetFilterActions` 负责翻页重置和两类项目筛选切换。
- `AssetFilterPanel` 只渲染选择器并触发动作。
- `filterAssetList` 使用统一画布归属判断过滤素材。

不新增持久化字段；筛选状态仍是页面会话状态。

## 边界与空状态

- 没有工作流项目或画布时，对应选择器禁用并显示明确占位。
- 已选择的项目或画布被删除后，自动清除无效筛选，避免页面保持空结果。
- 画布筛选下不显示只适用于工作流项目的集数、分镜组、项目库和过期引用筛选。
- 搜索、类型、收藏和名称排序均与项目筛选取交集。

## 验证

1. 纯函数测试覆盖画布素材库关联、当前生成记录和旧画布生成记录。
2. 筛选测试覆盖画布筛选与收藏、类型等条件叠加。
3. 类型检查验证页面、Hook 和组件接线。
4. 浏览器验证工作流项目、画布、全部项目之间切换，确认无残留筛选且布局在常见宽度下保持整洁。

## 非目标

- 不新增云端项目同步。
- 不修改素材所属关系或批量移动行为。
- 不支持同时选择多个工作流项目或多个画布。
- 不把工作流项目与画布筛选组合为交集查询。
