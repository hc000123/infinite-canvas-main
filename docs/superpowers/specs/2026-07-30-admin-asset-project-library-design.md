# 后台素材项目文件管理器设计

## 目标

把后台素材管理从“逐条填写完整表单”改成“先导入、后整理”的项目文件管理器。管理员只需新建独立素材项目，在项目和子文件夹中批量导入文件；系统自动生成素材名称、类型、访问地址和图片封面，分类、标签、描述与集数均在导入后按需整理。

这里的素材项目独立于前台项目中心，不读取或绑定浏览器本地项目数据。后台项目、文件夹和素材继续保存在服务端，作为所有用户可访问的公共素材库来源。

## 页面结构

### 项目首页

- 后台“素材管理”默认展示素材项目卡片，不再直接展示全部素材。
- 新建项目只要求填写名称；项目支持重命名和删除。
- 项目卡片展示素材数量和最近更新时间，点击后进入项目。
- 删除非空项目时明确提示会同时删除项目中的文件夹、素材记录和已上传文件，并要求二次确认。

### 项目文件管理器

- 左侧显示当前项目的多级文件夹树，支持新建、重命名和删除子文件夹。
- 顶部显示项目名称、当前路径、搜索、筛选、上传素材、新建文件夹和新建文本入口。
- 右侧以缩略图或列表展示当前文件夹素材；默认只看当前文件夹，可切换为搜索整个项目。
- 文件可拖入当前文件夹，也可通过文件选择器一次选择多个图片、视频和音频。
- 点击素材打开详情侧栏；勾选素材后显示批量操作栏。

## 导入与整理

### 文件导入

- 导入前不打开素材信息表单，不要求分类、标签、描述、封面 URL 或素材 URL。
- 名称默认使用去掉扩展名的原文件名，类型根据实际 MIME 自动识别。
- 图片使用自身作为封面；视频和音频不要求封面。
- 上传队列逐项展示等待、上传中、成功和失败状态。
- 单个文件失败不影响其他文件；失败项保留原因并支持重试。
- 上传成功的素材立即进入当前项目和文件夹。
- 继续沿用单文件 200 MB 上限，仅接受项目当前支持的图片、视频和音频格式。

### 文本素材

- 文本素材不经过文件上传，保留独立“新建文本”入口。
- 新建时只要求名称和文本内容；分类、标签、描述与集数仍可在保存后补充。

### 后续整理

- 单条详情支持修改名称、分类、标签、描述、适用集数和全剧通用状态。
- 批量操作支持移动文件夹、设置分类、追加或替换标签、设置适用集数、设为全剧通用和删除。
- 分类、标签和集数是筛选字段，不由文件夹名称自动推断。
- 集数支持多选；“全剧通用”与具体集数互斥，未整理素材允许二者都为空。
- 项目内可按关键词、媒体类型、分类、标签、集数和全剧通用状态筛选。

## 数据结构

新增独立的素材项目和素材文件夹：

- `asset_projects`：`id`、`name`、`created_at`、`updated_at`。
- `asset_folders`：`id`、`project_id`、`parent_id`、`name`、`created_at`、`updated_at`。

现有 `assets` 增加：

- `project_id`：所属素材项目。
- `folder_id`：所属文件夹；为空表示项目根目录。
- `episode_numbers`：适用集数数组。
- `all_episodes`：是否全剧通用。

项目与文件夹 ID 使用服务端生成 ID。文件夹只能在同一项目内形成层级；删除非空文件夹时连同其全部后代和素材一起删除，不做旧数据迁移或回收站。本项目尚未上线，现有无项目素材无需兼容展示。

## 接口与数据流

- 项目接口负责项目列表、新建、重命名和删除。
- 文件夹接口负责项目内文件夹树、新建、重命名和删除。
- 素材列表接口增加项目、文件夹、搜索范围、分类、集数和全剧通用筛选。
- 文件上传接口接收项目 ID 与可选文件夹 ID，上传成功后直接创建素材记录并返回完整素材，不再要求前端先上传文件再调用一次保存接口。
- 批量更新接口接收素材 ID 列表和明确的修改动作，用于移动、分类、标签和集数整理。
- 批量删除接口统一删除素材记录及其位于公共素材目录中的上传文件。
- 原公共 `/api/assets` 列表继续提供素材库读取能力，并支持按素材项目筛选；画布和生图工作台现有“素材库”入口继续使用同一素材数据。

## 错误与边界

- 项目名和同级文件夹名不能为空；同一父目录下不允许同名文件夹。
- 文件夹移动不得形成循环，也不得跨素材项目。
- 更新或删除前校验项目、文件夹和素材归属，避免通过 ID 操作其他项目内容。
- 上传文件以服务端检测到的 MIME 为准，不信任文件扩展名或浏览器声明。
- 删除上传文件只允许处理配置的公共素材目录内、且由素材库生成的路径；外部 URL 只删除记录，不请求或删除外部资源。
- 批量操作返回成功 ID 和失败项，前端保留选择并提示可重试内容。
- 火山素材审核继续挂在单个图片素材上；审核状态不作为上传前置条件。

## 验收

- 管理员可只填项目名称完成新建并进入项目。
- 项目内可创建至少两级子文件夹，并能通过面包屑和文件夹树切换。
- 一次选择多个支持格式的文件后无需补充表单即可开始上传，成功项自动生成名称、类型、URL 和图片封面。
- 批量上传中单个不支持或超限文件失败时，其他文件仍可成功，失败项可单独重试。
- 单条和批量操作均可设置分类、标签、多选集数和全剧通用；全剧通用与具体集数保持互斥。
- 当前文件夹浏览和整个项目搜索的结果范围正确，类型、分类、标签和集数筛选可组合使用。
- 后台上传的素材仍可从公共素材库和画布素材选择器读取与插入。
- 删除项目、文件夹或素材后，数据库记录和项目素材目录内对应上传文件同步移除，外部 URL 不受影响。

## 非目标

- 不绑定前台项目中心或用户本地项目。
- 不增加素材审批、版本历史、回收站、权限分组或重复文件检测。
- 不在导入时根据文件名自动推断角色、场景、道具或集数。
- 不改变“我的素材”仍以浏览器本地存储为主的现状。
