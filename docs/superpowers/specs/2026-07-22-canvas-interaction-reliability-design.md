# 画布交互可靠性优化设计

## 目标

解决画布中删除、缩放、提示词引用、长文本编辑和提示词模板关闭五类直接影响创作效率的问题，同时保持现有画布数据、本地持久化和生成接口边界不变。

## 已确认问题

1. 节点和连线删除依赖画布焦点。节点与连线点击会阻止事件继续到画布根层，导致选中后 `Delete / Backspace` 可能被忽略；连线没有可见删除入口。
2. 画布缩放需要与浏览器缩放分离。普通滚轮用于画布缩放，`Ctrl / Cmd + 滚轮` 和 `Ctrl / Cmd + 加减号` 保留给浏览器。
3. `@` 候选列表有缩略图，但选中后只留下“图片 1”纯文本，无法持续辨认或稳定绑定具体图片节点。
4. 文本节点只能在节点尺寸内编辑，长文本缺少扩大编辑区域的按钮。
5. 提示词库主弹窗、详情弹窗和新建弹窗分别维护状态，关闭主层时没有统一清理嵌套状态，也缺少交互回归测试。

## 设计方案

### 1. 统一删除动作

- 增加单一的画布选中删除动作，根据当前选择删除节点集合或单条连线。
- 节点悬浮工具栏、底部工具栏、节点右键菜单、连线删除按钮和键盘快捷键复用同一动作。
- 节点或连线被选中时主动把焦点交给画布根容器；输入框、富文本编辑器、弹窗和抽屉内仍禁止触发画布删除。
- 连线选中后在路径中部显示低视觉重量的删除按钮，并支持右键删除。
- 删除节点时继续删除关联连线、批次子节点并清理当前节点相关 UI 状态；删除连线时只移除该连接。

### 2. 滚轮缩放与浏览器快捷键分离

- 鼠标位于画布且没有按下 `Ctrl / Cmd` 时，滚轮围绕指针位置缩放画布。
- `Ctrl / Cmd + 滚轮` 不调用画布缩放，也不阻止浏览器默认行为。
- 不注册 `Ctrl / Cmd + 加号`、`Ctrl / Cmd + 减号` 等画布缩放快捷键。
- 底部缩放滑杆和重置视图继续保留，快捷键说明明确写为“滚轮：缩放画布”。
- 输入框、弹窗、下拉菜单和标记了 `data-canvas-no-zoom` 的区域不触发画布缩放。

### 3. 提示词内嵌图片引用

视频提示词编辑器改为支持行内引用节点的富文本编辑器。采用成熟的 Lexical 编辑器，仅封装画布提示词所需的文本与图片引用能力，不引入通用富文本系统。

行内图片引用表现为：

- 在提示词文本中直接显示图片缩略图、引用序号和节点标题。
- 引用节点不可拆分编辑，方向键可以跨过，`Backspace / Delete` 一次删除整个引用。
- 点击引用打开图片预览；辅助操作可定位到对应画布节点。
- 对应图片节点不存在或不再连接时，引用显示失效状态，提交前给出明确提示。

数据结构在视频节点 metadata 中新增结构化提示词文档：

```ts
type CanvasPromptDocument = {
    version: 1;
    blocks: Array<
        | { type: "text"; text: string }
        | { type: "reference"; nodeId: string; kind: "image"; label: string }
    >;
};
```

- `nodeId` 是引用身份，显示序号不是身份。
- 每次生成前，根据当前上游连接顺序为有效引用重新计算“图片 1、图片 2”。
- 提交给现有视频接口时把结构化文档序列化为纯文本，引用节点输出当前官方标签；接口仍接收现有 prompt 字符串和媒体数组。
- `metadata.prompt` 保留序列化后的纯文本，供生成记录、资产归档、信息弹窗和重试使用；`metadata.promptDocument` 负责编辑器恢复和真实节点绑定。
- 提示词模板插入为普通文本块，不自动伪造图片引用。

### 4. 文本节点扩大编辑

- 文本节点悬浮工具栏和节点编辑态增加“展开编辑”按钮，图标使用 `Maximize2`。
- 点击后打开画布主题下的大尺寸 Modal，正文编辑区高度约为视口的 70%，适合长文本输入。
- 弹窗使用本地草稿；点击“保存”一次写回节点，点击“取消”不修改节点，避免误关闭造成内容变化。
- 字号调整继续作用于节点显示，不影响扩大编辑器的可读字号。
- 弹窗打开时画布快捷键和滚轮缩放均不响应。

### 5. 提示词模板关闭状态

- 为提示词库提供统一 `closeDialog`，同时清理主弹窗、提示词详情和新建提示词状态。
- 右上角关闭、页面内关闭按钮、遮罩点击和 `Escape` 统一调用该动作。
- 主弹窗隐藏后销毁其临时内容，重新打开时不恢复上次详情层或新建层。
- 选择并插入提示词后关闭全部模板层，焦点回到发起编辑器。

## 组件边界

- `use-canvas-keyboard-shortcuts.ts` 只判断快捷键作用域并调用统一删除动作。
- 节点和连线的实际删除保持在画布业务 hook 中，不放进展示组件。
- 新增画布私有 `CanvasPromptEditor`，负责 Lexical 配置、引用节点渲染和文档序列化。
- 引用序号计算与纯文本序列化放在 `canvas/utils/` 的纯函数中。
- 文本扩大编辑 Modal 放在画布组件目录，通过节点 ID 和保存回调工作，不直接操作 Store。
- 提示词库继续使用现有公共组件，只收敛其关闭状态，不重构提示词查询和管理功能。

## 错误与边界处理

- 失效图片引用不静默改指其他图片；生成前提示用户删除失效引用或重新连接原节点。
- 同一图片允许在提示词中出现多次，但媒体输入仍按连接节点去重并保持稳定顺序。
- 删除被引用图片节点后，视频节点提示词文档保留失效引用，便于用户识别和修复，不自动删除文本语义。
- 画布未获得焦点时不响应删除；选择节点或连线会主动恢复画布焦点。
- 浏览器缩放组合键永远不修改画布 viewport。

## 验收标准

1. 从按钮、右键菜单或键盘删除节点，节点及关联连线立即消失；撤销可恢复。
2. 选中连线后能看到删除入口，键盘和按钮都只删除目标连线。
3. 普通滚轮只缩放画布；`Ctrl / Cmd + 滚轮` 和浏览器加减号快捷键只影响浏览器。
4. 输入 `@` 选择图片后，缩略图引用直接出现在提示词文本中，保存和刷新后仍绑定同一节点。
5. 调整连接顺序后，引用显示身份不变，提交标签按新顺序重新编号。
6. 删除引用图片节点后，提示词显示失效引用且不能无提示提交。
7. 文本节点可打开大编辑器；取消不保存，保存后节点内容更新。
8. 提示词库从主层、详情层和新建层都可关闭；重新打开不残留旧的嵌套弹窗。

## 测试计划

- 纯函数测试：提示词文档序列化、引用重新编号、重复引用、失效引用检测。
- 组件测试：Lexical 图片引用插入、整块删除、保存恢复和点击预览。
- 交互测试：画布焦点切换后的节点/连线删除、输入框内 Delete 不删除画布内容。
- 交互测试：普通滚轮画布缩放、带修饰键滚轮不修改 viewport。
- 交互测试：文本扩大编辑保存/取消，提示词库四种关闭路径及嵌套状态清理。

## 不做事项

- 不改变后端视频接口或 Seedance 媒体协议。
- 不把所有画布文本输入统一改造成富文本编辑器。
- 不新增云端同步、多人协作或历史数据迁移。
- 不重构画布节点、生成流程或提示词库的无关业务。
