# 腾讯 MPS 增强模板同步设计

## 目标

让管理员从腾讯云 MPS 只读同步当前账号可见的音视频增强模板，在后台明确启用可用方案，并让画布按已启用方案提交任务。模板同步不上传视频、不调用 `ProcessMedia`、不产生增强任务费用；每个付费任务仍冻结唯一模板 Definition ID，保持现有恢复与防重复提交边界。

首版继续只允许 1080p 与 2K 输出进入画布。腾讯返回但无法确认输出规格，或输出不属于 1080p / 2K 的模板，只展示为“暂不支持”，不能启用或提交。这样可以加载其他官方或自定义预设，同时不悄悄扩大现有 4K 成本和输出能力范围。

## 已确认方案与备选方案

### 方案 A：后台同步并保存启用快照（采用）

- 管理员主动点击“同步腾讯模板”。
- 后端使用已保存的 SecretId / SecretKey 调用 `DescribeTranscodeTemplates`，限定 `TranscodeType=Enhance`，分页读取模板。
- 前端把同步结果合并进当前设置表单；管理员启用、命名和归类后，沿用页面统一“保存设置”提交。
- 画布能力接口只返回已启用且规格有效的模板，任务提交时再次在服务端校验并冻结 Definition ID。

优点是画布不依赖腾讯接口实时可用，管理员能控制成本与能力范围，现有任务也不会受后续模板修改影响。

### 方案 B：每次打开画布时实时读取腾讯模板（不采用）

模板变化能立即出现，但会把腾讯网络、权限和限流故障带入普通创作流程，也无法形成稳定的管理员允许列表。

### 方案 C：只提供手填 Definition ID（不采用）

实现最少，但无法确认模板类型、输出尺寸、编码和计费边界，容易把错误模板带入付费任务。

## 数据结构

继续复用 `settings` JSON，不新增数据库表。`TencentMPSVideoSetting` 增加模板快照列表：

```text
templates[]
  definition       腾讯模板 Definition ID
  upstreamName     腾讯返回的模板名称
  displayName      管理员在画布看到的名称
  sourceType       Preset / Custom
  enabled          是否允许画布使用
  scene            comic / live / restore / custom
  target           1080p / 2k
  width / height   腾讯返回的输出尺寸
  codec            腾讯返回的编码格式
  fps              0 表示保持源帧率，否则记录模板帧率
  removeAudio      腾讯模板是否移除音频
  supported        是否满足当前画布能力边界
```

现有六个官方模板作为内置种子：

| 场景 | 1080p | 2K |
|---|---:|---:|
| 漫剧增强 | 327004 | 327006 |
| 真人增强 | 327003 | 327005 |
| 老片修复 | 327022 | 327023 |

升级后如果模板列表为空，规范化设置时写入这六个种子并默认启用，保持当前行为。已有模板快照按 Definition 合并，管理员设置的 `enabled / displayName / scene / target` 优先保留；腾讯同步只刷新上游名称、来源、尺寸、编码和帧率。

同步发现的新模板默认禁用，默认显示名称使用腾讯模板名称。Definition 必须能解析成正整数；重复 ID 按第一次有效结果去重。只有包含视频增强配置、保留音频，且输出规格能可靠归入 1080p 或 2K 时才标记 `supported=true`：自适应横竖版模板的长短边必须分别为 `1920×1080` 或 `2560×1440`。不从普通名称猜测尺寸；优先读取腾讯 `VideoTemplate.Width / Height`，内置六个模板使用已确认映射。

## 后端接口与调用边界

新增管理员接口：

```text
POST /api/admin/settings/tencent-mps-templates/sync
```

接口只接受当前表单里的腾讯设置，用与现有连接测试相同的方式恢复已保存密钥；返回脱敏模板摘要，不直接保存设置。同步使用官方 SDK 的 `DescribeTranscodeTemplates`，不调用提交、上传、删除或修改模板接口。

腾讯 MPS 客户端增加只读 `ListEnhancementTemplates` 能力。连接测试继续查询官方模板 `327004`；同步接口以每页 100 条读取，最多接收 500 条并去重 Definition，避免异常账号数据导致无界请求。上游错误转换为安全中文提示，不记录密钥或原始签名信息。

视频任务提交新增 `tencentTemplateId`：

- 腾讯渠道必须提交一个已启用、受支持的模板 ID。
- 服务端从已保存允许列表查找模板，不信任前端传来的名称、场景或分辨率。
- 创建 Job 时冻结模板 ID、显示名称、场景、目标、COS Bucket、地域与前缀；`video_upscale_jobs` 增加 `tencent_template_name` 字段用于任务和节点追溯，数据库文档同步更新。
- 已有 Job 继续按自身冻结字段恢复；同步或禁用模板不影响历史任务。
- 未知、已禁用或不支持的模板在上传 COS 和调用 MPS 前拒绝，不产生付费任务。

## 后台交互

在现有“腾讯 MPS 视频增强”区域增加紧凑的“增强方案”区：

- 右上角提供“同步腾讯模板”，并注明“只读取模板，不创建任务”。
- 列表每行显示启用开关、显示名称、腾讯模板 ID、官方/自定义来源、输出规格和编码。
- 内置六个方案自动带入中文名称与场景；新同步模板默认关闭。
- 受支持的新模板允许设置画布显示名称，并从“漫剧 / 真人 / 老片 / 自定义”中选择用途；目标清晰度由已确认输出尺寸确定，不让管理员伪造。
- 无法确认规格或超出 1080p / 2K 的模板显示原因并禁用开关。
- 同步只更新当前表单，仍需点击页面统一“保存设置”；同步失败不清空现有列表。

视觉保持当前后台的低重量工具面板：不新增大卡片、渐变、阴影或独立向导，复用 Ant Design `Button / Switch / Input / Tag / Segmented` 和现有主题变量。

## 画布交互

腾讯渠道不再让用户分别组合“场景 + 清晰度”，而是展示一个“增强方案”选择器，直接列出管理员已启用模板，例如：

```text
漫剧增强 · 1080p
真人增强 · 2K
自定义清晰化 · 1080p
```

方案切换后，目标尺寸说明取模板快照；源视频已经达到或超过该模板目标短边时禁用提交。腾讯渠道继续固定保留音频、保持模板定义的帧率行为，不显示 LAS 编码质量、插帧和费用估算控件。提交按钮仍明确提示腾讯增强与转码分别计费。

## 错误与安全处理

- 未配置或禁用腾讯渠道时不能同步。
- 同步没有可见模板时保留当前列表，并提示未读取到增强模板。
- 重复 Definition 只保留一条；无法解析的 Definition 不进入设置。
- API、日志、能力接口和画布节点不返回 SecretId / SecretKey。
- 同步不自动启用新模板，不自动保存，不创建付费任务。
- 任务提交失败不自动切换模板或重试其他模板。
- 不删除腾讯控制台模板，也不清理历史 COS 对象。

## 测试与验收

后端测试先覆盖：

- 同步只调用 `DescribeTranscodeTemplates`，不调用 `ProcessMedia`。
- 分页、去重、无效 Definition 和上游错误处理。
- 内置六模板种子与同步合并保留管理员选择。
- 保存设置继续脱敏并保留密钥。
- 未知、禁用和不支持模板在付费提交前被拒绝。
- 合法模板 ID、场景、目标与 Definition 被冻结到 Job。

前端测试先覆盖：

- 管理后台存在同步入口、只读说明、启用管理和统一保存边界。
- 同步合并不覆盖管理员本地启用状态。
- 画布只展示能力接口返回的已启用模板，并提交具体模板 ID。
- 腾讯渠道不显示 LAS 插帧、输出质量和金额估算。

人工验收使用无计费同步：后台同步后核对内置与自定义模板、刷新后的启用状态、连接测试和画布方案列表。未经新的明确授权，不再提交第二个真实腾讯付费视频任务。

## 非目标

- 本轮不创建、修改或删除腾讯云模板。
- 本轮不支持 720p、4K 或无法确认输出尺寸的模板提交。
- 本轮不为腾讯模板伪造费用估算。
- 本轮不改变火山 LAS、智能插帧、字幕擦除、结果归档或任务恢复链路。
