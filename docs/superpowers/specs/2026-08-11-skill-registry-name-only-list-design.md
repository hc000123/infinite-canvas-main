# Skill 注册表仅名称列表设计

## 目标

后台 `/admin/skills` 左侧注册表只承担快速浏览和选择 Skill 的职责。Skill 选择项仅显示名称，避免摘要、Capability 和输入输出契约重复占用侧栏空间。

## 界面行为

- 每个 Skill 选择项只显示 Skill 名称。
- 保留当前选中边框、选中背景、悬停反馈和整项点击切换行为。
- 保留阶段折叠分组、阶段名称和数量标签。
- 名称过长时允许自然换行，不产生横向溢出。
- Skill 摘要、Capability、输入 Artifact 和输出 Artifact 继续在右侧详情中查看，不在左侧重复展示。

## 实现边界

- 只修改后台 Skill 中心的 `SkillCard` 展示内容与紧凑间距。
- 不修改 Skill 数据结构、筛选、排序、分组、选中状态或详情面板。
- 不新增图标、悬浮说明或新的全局样式。

## 验收

1. 展开任一阶段，确认每个 Skill 选择项只显示名称。
2. 点击不同名称，确认右侧详情正常切换，选中态清晰。
3. 确认长名称在卡片内换行，无横向溢出。
4. 确认阶段分组、数量、折叠和搜索筛选行为不变。

## 回归测试

增加源码契约测试，确保 `SkillCard` 不再渲染摘要、Capability 标签和输入输出文本，并保留名称与点击按钮。
