# 画布目标节点驱动生成设计

## 目标

让画布连线符合“目标节点决定生成类型”的直觉：文本连接图片后由图片节点生图，文本连接视频后由视频节点生视频，文本连接文本后由语言模型优化文本。连线只建立输入关系，不自动调用模型，也不产生费用。

生成配置节点继续保留，但只作为批量数量、模型参数、输入排序和多素材编排的高级入口，不再是文本生成图片或视频的必经节点。

## 核心规则

| 上游输入 | 目标节点 | 生成语义 |
| --- | --- | --- |
| 文本 | 图片 | 上游文本作为生图提示词，目标节点输入框作为可选补充要求 |
| 文本 | 视频 | 上游文本作为视频提示词，目标节点输入框作为可选补充要求 |
| 文本 | 文本 | 上游文本作为待优化原文，目标节点输入框作为可选优化要求 |
| 图片 | 图片 | 上游图片作为参考图，执行图生图 |
| 图片 | 视频 | 上游图片作为视频参考图 |
| 多个文本或媒体 | 图片、视频或文本 | 目标节点决定模型类型，上游节点按现有输入顺序参与生成 |

目标节点自己的生成模式始终由节点类型确定：图片节点为 `image`，视频节点为 `video`，文本节点为 `text`。生成配置节点仍使用自身的 `generationMode`。

## 交互设计

1. 从节点输出端拖到画布空白处时，继续显示创建菜单。
2. 选择“图片生成”时创建空图片节点并连线；选择“视频生成”时创建空视频节点并连线；选择“文本优化”时创建空文本节点并连线。
3. 创建后选中目标节点并打开其生成面板，但不自动生成。
4. 直接连接已有目标节点时，同样选中目标节点并打开生成面板，但不自动生成。
5. 目标节点生成面板展示上游已连接输入。连接文本存在时，输入框改为“补充要求”的语义，不把上游文本复制进目标节点，避免重复和失去实时引用。
6. 文本节点连接空文本节点后，如果用户没有填写优化要求，生成时自动使用默认要求：保持原意，优化表达，使内容更清晰、自然、完整。
7. 文本节点上的“生图”快捷按钮创建空图片节点并连接，随后打开图片节点生成面板；不再创建生成配置节点，也不立即生成。

## 数据流

连线仍是唯一输入关系来源，不新增持久化字段。生成时继续通过现有 `buildCanvasGenerationContext` 读取目标节点的所有上游输入：

1. 上游文本拼接为基础提示词。
2. 目标节点输入框内容作为补充要求。
3. 上游图片、视频和音频继续转为相应参考素材。
4. 点击目标节点“生成”后，现有图片、视频或文本生成 action 执行请求。

提示词组合顺序统一为“上游文本在前，目标节点补充要求在后”。没有补充要求时只提交上游文本；没有上游文本时保持现有行为，只提交目标节点输入框内容。

文本优化是唯一需要默认补充要求的路径：当目标为空文本节点、有上游文本且目标输入框为空时，注入默认优化要求。默认要求只参与本次请求，不写入节点内容。

## 节点结果规则

- 空图片节点：生成结果回填当前图片节点；数量大于一时沿用现有子图规则。
- 空视频节点：生成结果回填当前视频节点。
- 空文本节点：语言模型结果回填当前文本节点。
- 已有媒体节点：沿用现有节点内版本生成规则。
- 已有内容的文本节点：沿用现有文本改写规则，生成新的文本结果节点；上游文本作为附加上下文。
- 生成配置节点：行为不变。

## 异常与边界

- 目标节点既没有本地提示词，也没有有效上游文本时，生成按钮保持不可用。
- 上游空文本节点不计为有效输入。
- 删除连线后，目标节点立即停止读取该输入，不保留隐式副本。
- 多个上游文本按目标节点现有 `inputOrder` 拼接。
- 连接本身不检查 AI 配置；用户点击生成时继续沿用现有配置检查和错误提示。
- 配置节点之间仍禁止连接，其他现有连接限制保持不变。

## 实现边界

- 调整连接完成后的选中与生成面板打开行为。
- 调整创建菜单中文案，使“文本生成”明确为“文本优化”。
- 将文本节点“生图”快捷动作从创建配置节点改为创建图片节点。
- 调整生成上下文的文本组合顺序，并增加文本优化默认要求。
- 补充相关纯函数或组件测试。
- 更新画布节点手册、待测试记录和待办状态。

不修改 AI 接口协议、节点持久化结构、媒体版本结构、生成配置节点的数据结构或素材归档路径。

## 验收标准

1. 文本连接空图片节点后不会自动生成；打开图片面板并点击生成才发起请求。
2. 文本连接空视频节点后不会自动生成；打开视频面板并点击生成才发起请求。
3. 文本连接空文本节点后，目标输入框为空也可点击生成，并使用默认优化要求。
4. 目标输入框填写补充要求时，请求文本顺序为上游文本在前、补充要求在后，且不重复。
5. 修改上游文本后再次生成，目标节点读取最新文本。
6. 文本节点点击“生图”只创建并连接空图片节点，不创建配置节点、不发起生成。
7. 高级用户仍可手动创建生成配置节点并使用原有批量及参数能力。
