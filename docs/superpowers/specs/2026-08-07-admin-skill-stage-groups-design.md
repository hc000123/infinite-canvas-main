# 管理后台 Skill 阶段分组设计

## 背景

`/admin/skills` 当前将所有 Skill 卡片连续展示。随着系统 Skill、项目 Skill 和外部导入 Skill 增加，注册表页面过长，制作人员难以按生产流程定位目标 Skill。

本次只调整 Skill 注册表的组织与展开方式，不改变 Skill 数据模型、导入流程、版本管理和卡片内操作。

## 目标

- 按生产阶段收纳 Skill，减少页面初始展示长度。
- 保留现有搜索、筛选、选择、编辑、启停、删除和版本操作。
- 用户选中 Skill 或执行搜索时，自动展示相关阶段，避免额外寻找。
- 对缺少阶段字段的现有 Skill 提供稳定、可测试的归类规则。

## 非目标

- 不新增数据库字段或迁移。
- 不修改外部 Skill 文件夹和单文件导入协议。
- 不重做 Skill 卡片样式。
- 不改变工作流运行时的 Skill 选择与调用逻辑。
- 不引入侧边栏导航或真正的侧滑 Drawer。

## 页面结构

注册表筛选区下方使用 Ant Design `Collapse` 展示非空阶段组。每个阶段是一个可独立展开的折叠面板，内部继续使用现有 Skill 卡片网格。

阶段按以下固定顺序展示：

1. 剧本与内容分析
2. 资产提取
3. 资产设计 / Brief
4. 资产成图
5. 分镜
6. 镜头提示词 / 视频
7. 成片交付
8. 其他

折叠面板标题显示阶段名称、当前可见 Skill 总数，以及系统 Skill 和项目 Skill 的数量。没有可见 Skill 的阶段不渲染。

## 归类规则

阶段归类是前端展示层的纯计算，不回写 Skill 数据。

1. 优先使用 Skill 的 `stageKey`。
2. `stageKey` 缺失或无法识别时，依次根据 capability、输入/输出 artifact 类型进行回退分类。
3. 无法确定阶段时归入“其他”，不得丢失或隐藏 Skill。

回退分类至少覆盖当前内置能力：

- `workflow.stage.script`、`content.classify`：剧本与内容分析。
- `workflow.stage.art`：资产提取。
- `asset.brief.*`、`workflow.stage.assets`：资产设计 / Brief。
- `asset.rendition.*`：资产成图。
- `storyboard.*`、`workflow.stage.storyboard`：分镜。
- `workflow.stage.video`：镜头提示词 / 视频。
- `workflow.stage.delivery`：成片交付。

当多个信号冲突时，`stageKey` 优先；回退规则采用固定匹配顺序，保证同一 Skill 每次只进入一个阶段。

## 展开行为

- 当前存在选中 Skill 时，默认展开其所在阶段。
- 当前没有选中 Skill 时，默认展开第一个包含可见 Skill 的阶段。
- 用户手动展开或收起阶段后，页面在当前筛选状态内保留该操作结果。
- 搜索词或筛选条件发生变化时，自动展开所有包含匹配结果的阶段。
- 清空搜索和筛选后，恢复到选中 Skill 所在阶段；没有选中 Skill 时恢复到第一个非空阶段。
- 点击 Skill 卡片继续使用现有选中与详情编辑行为，不改变路由和保存流程。

## 组件与代码边界

- `skill-view.ts`：新增阶段定义、单个 Skill 归类和可见 Skill 分组纯函数。
- `page.tsx`：使用分组结果渲染 `Collapse`，管理展开面板状态，继续复用现有 Skill 卡片。
- 不新增全局 store；展开状态是页面私有 UI 状态。
- 不修改 API service 和后端模型。

## 空状态与异常处理

- 全部筛选结果为空时，沿用现有空状态，不展示空折叠面板。
- 单个 Skill 数据缺字段时归入“其他”，页面不得崩溃。
- 阶段数量由当前可见结果计算，确保标题数量与实际卡片一致。

## 测试

先增加失败测试，再实现生产代码。

纯函数测试覆盖：

- `stageKey` 优先归类。
- capability 和 artifact 回退归类。
- 未知 Skill 进入“其他”。
- 阶段固定排序，空阶段不返回。
- 系统 Skill、项目 Skill 和总数统计准确。

页面 wiring 测试覆盖：

- 注册表使用 `Collapse` 渲染阶段组。
- 选中 Skill 时展开对应阶段。
- 搜索或筛选时展开所有匹配阶段。
- Skill 卡片仍由现有点击与编辑逻辑处理。

## 验收标准

- `/admin/skills` 初次打开时不再完整展开所有 Skill。
- 所有当前可见 Skill 均且仅出现在一个生产阶段中。
- 展开、收起、搜索、筛选和选择 Skill 的行为符合本设计。
- 现有 Skill 卡片操作和外部导入入口不受影响。
- 相关前端测试通过。
