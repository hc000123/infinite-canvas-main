# 移除项目级素材引用页签设计

## 目标

从项目详情页移除“素材引用”页签，减少项目导航中的低频管理入口。素材引用数据、固定版本快照、画布与工作流生成引用保持不变。

## 方案

- 项目详情导航只保留“分集”和“画布”等现有主要入口，不再渲染项目级素材引用面板。
- 项目总览继续计算素材缺口和旧版本引用，用作风险提醒；相关指标与建议改为进入带项目上下文的“我的素材”。
- “我的素材”继续承担素材详情、引用位置、过期引用更新和项目库管理。
- 删除仅供项目素材引用页签使用的组件状态、属性和展示代码；不删除通用的引用聚合、版本管理和生成链路代码。

## 数据流

项目详情不再消费素材引用列表进行页签渲染。画布节点的 `sourceAssetId`、`assetVersion`，分镜与镜头组的 `assetRefs`，以及视频工作流的 `referenceBindings` 均保持原样。项目总览需要的统计仍从现有聚合结果计算，点击后跳转 `/assets?projectId=<项目ID>`。

## 边界

- 不迁移或删除浏览器本地数据。
- 不修改图片、视频生成请求。
- 不修改“我的素材”中的过期引用更新能力。
- 不新增新的项目素材库页面或筛选协议。

## 验收

- 项目详情不再显示“素材引用”页签。
- 项目总览的素材风险入口不再尝试切换到已删除页签，而是打开当前项目素材库。
- 现有画布、分镜、设定库和视频工作流引用代码保持可用。
- `docs/todo.md` 与 `docs/pending-test.md` 不再把项目级素材引用页签列为当前待验收功能。
