# 画布素材选择器批量选择与筛选设计

## 目标

将画布“选择素材”从逐项插入改为批量选择器，并让本集素材、我的素材和云端素材库都具备与自身数据字段匹配的完整筛选能力。

## 交互

- 素材卡片点击后切换选中状态，使用边框、勾选框和选中底色提供反馈，不再点击即插入。
- 选择状态由弹窗统一维护，切换 Tab、筛选和翻页不会丢失；同一条本地素材在“本集素材”和“我的素材”中使用同一选择键，避免重复导入。
- 底部固定操作区显示已选数量，提供清空与“导入所选”；导入期间锁定关闭操作并显示加载状态。
- 本集素材和我的素材支持全选当前筛选结果；云端素材库只能全选当前页，避免把尚未加载的远端结果误算为已选择。
- 每次重新打开弹窗时清空上次选择，不默认全选本集素材。

## 筛选

- 本集素材：关键词、角色 / 场景 / 道具 / 其他分类、资产主体、全剧通用 / 仅本集、排序。
- 我的素材：关键词、文本 / 图片 / 视频 / 音频类型、资产分类、全部 / 当前项目 / 当前集 / 未归类范围、文件夹、收藏、排序。
- 素材库：关键词、素材类型、多个标签，并保留服务端分页。
- 搜索覆盖标题、标签、备注、来源、形态名称和资产主体名称；所有筛选区提供重置入口。

## 数据流

本地素材选择项直接保存可生成 `InsertAssetPayload` 的资产快照；远端素材选择项保存延迟加载函数，在用户确认时下载和转换。批量导入逐项解析和插入，单项失败不阻断其他素材，最后汇总成功与失败数量。

## 画布插入

现有单素材插入动作改为可等待的异步动作，弹窗负责在整批结束后关闭。图片节点 ID 增加随机后缀，避免同一毫秒批量插入时冲突；现有节点避让排布逻辑继续负责把新节点放到画布空位。
