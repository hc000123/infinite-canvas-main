# 缓存文件卡片预览设计

## 目标

将缓存管理页中的文件长表格改为更紧凑的响应式卡片，并让已缓存的图片、视频和音频可以在页面内预览，也可以通过安全的新标签页查看原文件；现有搜索、筛选、删除、移动、项目打包和缓存清理能力保持不变。

## 信息架构

- 左侧继续按项目展示缓存概览，项目磁盘清单无法在当前浏览器项目库中匹配时显示“未关联当前项目”，与“文件缺失”状态明确区分。
- 右侧保留项目标题、缓存目录、项目包和清理操作，以及已有搜索、分集、分类和媒体类型筛选。
- 文件区改为响应式网格：窄屏一列，中等宽度两列，宽屏按可用空间扩展到三至四列。
- 每张卡片展示预览区、文件名、分类、分集、大小和缓存状态，并保留删除及未归属文件的移动操作。

## 预览与原文件查看

- 图片卡片在进入视口后，通过现有 Bearer 鉴权接口获取 Blob 并显示真实缩略图；组件卸载或文件变化时释放对象 URL。
- 视频卡片进入视口后按需加载原文件并显示真实首帧，音频卡片仍只显示类型封面。
- 点击可用卡片打开页面内预览弹窗；图片、视频和音频均在弹窗打开后加载，视频和音频使用浏览器原生控制器。
- 卡片操作提供“新标签查看原文件”，打开应用内 `/cache/files/:fileId` 查看页。查看页从当前用户状态读取令牌，再通过鉴权接口获取 Blob 并创建对象 URL，不把令牌和磁盘绝对路径写入 URL。
- 查看页按媒体类型渲染图片、视频或音频，并提供下载按钮。Blob 获取失败、未登录或磁盘文件缺失时显示明确错误状态。
- 缺失文件不加载缩略图、不可预览或新标签查看，但仍可删除清单记录。

## 接口与安全边界

- 复用 `GET /api/v1/project-cache/files/:id`，不新增公开静态目录、签名地址或后端路由。
- 前端服务层新增获取文件 Blob 的方法，统一附带 Bearer 令牌，并从响应头和 Blob MIME 推断展示信息。
- 当前版本允许浏览器完整加载视频和音频 Blob；Range 流式传输不在本次范围内。
- 不提供从缓存清单重新关联浏览器项目的功能，也不修改浏览器本地项目和磁盘缓存的持久化模型。

## 视觉与交互

- 沿用 `studio-*` 主题变量、Ant Design 组件和现有缓存页层级，不硬编码独立明暗主题。
- 卡片预览区使用固定宽高比，媒体内容 `object-contain`，避免裁切原图；视频和音频封面使用低视觉重量的图标与类型文字。
- 卡片本体可点击预览，操作按钮阻止冒泡，避免删除、移动或新标签查看时误开弹窗。
- 加载使用局部骨架或旋转状态，不阻塞整个缓存页；缩略图失败只影响对应卡片。

## 验收

- 缓存文件以响应式卡片展示，常用信息和现有管理动作完整保留。
- 图片卡片可见真实缩略图，视频卡片可见真实首帧，音频卡片不会在列表阶段加载原文件。
- 点击正常文件可在弹窗内预览；关闭弹窗后对象 URL 被释放。
- “新标签查看原文件”能在同一登录会话中打开安全查看页并播放或显示媒体，地址栏不含令牌和磁盘路径。
- 缺失、未登录和接口失败都有明确状态，不出现空白页。
- 原“本地项目不存在”文案改为“未关联当前项目”，文件缺失仍单独显示。
