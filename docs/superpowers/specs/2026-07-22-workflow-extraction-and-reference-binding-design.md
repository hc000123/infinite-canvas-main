# 视频工作流信息提取与参考图绑定设计

## 目标

把单集视频工作流调整为“AI 先生成生产草稿，用户只修正和确认”的低确认流程：

1. 原剧本可直接编辑和保存。
2. 资产信息与结构化分镜都由可替换 Skill 从当前剧本中提取。
3. 资产图片可生成，也可从本地或素材库导入并绑定资产编号。
4. 分镜确认后，再为当前镜头选择、导入并定义参考图。
5. 参考图、原剧本和已确认分镜共同生成视频提示词；提示词自动保存，只需最终确认。

本次只调整视频工作流及项目分集的剧本编辑入口，不改画布、模型设置页或后台 Skill 管理页面的编辑能力。

## 核心流程

```text
编辑并保存原剧本
  ├─ 资产提取 Skill ─→ 资产卡 ─→ 生成或导入资产图
  └─ 分镜提取 Skill ─→ 结构化分镜草稿 ─→ 人工修改并确认
                                            ↓
                                  定义并绑定镜头参考图
                                            ↓
                                  生成、修改并确认提示词
                                            ↓
                                         生成视频
```

资产提取与分镜提取都只依赖当前剧本，可以并行运行。视频提示词仍然依赖已确认分镜和当前有效参考图。

## 剧本编辑与版本状态

### 项目中心

- “原剧本”区域从只读预览改为“阅读 / 编辑”双态。
- 编辑态直接修改正文，提供“保存修改”。
- 保存后更新当前分集的原剧本文本；如果已有 AI 优化稿，则将优化稿和结构稿标记失效，视频工作流先读取修改后的原文，直到用户重新运行剧本优化。
- 新剧本文本产生新的工作流剧本摘要和运行版本；旧运行与产物保留用于追溯，不继续作为当前生产输入。
- 已有资产、分镜和提示词不删除，只标记为“剧本已更新，需要重新提取或重新生成”。
- 后续步骤使用明确的剧本版本或内容摘要判断是否过期，避免静默沿用旧结果。

### 视频工作流剧本确认页

- 展示当前生产剧本及版本状态。
- 增加“信息提取”区域，包含“资产提取 Skill”和“分镜提取 Skill”两个独立选择器。
- 默认选中后台对当前项目生效的已发布 Skill 版本。
- 用户切换 Skill 只影响本集下一次对应阶段运行，不修改全局或项目默认绑定。
- “开始提取”直接把资产和分镜任务加入后台队列，不增加额外确认弹窗；任务可以并行，页面可继续操作。
- 单项失败不取消另一项，失败项提供“重新提取”。

## 运行时 Skill 选择

### 用户可见数据

新增只读接口，按阶段返回当前用户可使用的已发布 Skill 版本：名称、版本、说明、是否为项目默认。接口不返回可编辑文件或管理权限数据。

本次前台开放两个阶段：

- `asset-extraction`
- `shot-breakdown`

### 启动阶段

阶段启动参数增加可选的 `skillVersionId`。后端必须校验：

- 版本存在且已发布；
- 版本所属 Skill 与目标阶段一致；
- 用户可以访问当前项目；
- 没有传入覆盖版本时继续使用项目级或全局默认绑定。

执行任务继续冻结 Skill ID、版本号、内容摘要和完整快照，保证重试与审计可复现。用户选择不会写回 `workflow_stage_skill_bindings`。

任务启动后，页面从最新 Agent Run 读取并展示实际冻结的 Skill 版本；未启动的新任务仍默认显示项目级或全局生效版本，避免前端另存一份可能过期的 Skill 配置。

## 资产设计与导入

### 资产卡

- 保留角色、场景、道具分类以及角色马甲归属关系。
- 每张资产卡增加“导入资产”，与“生成草图”并列。
- 点击后提供“本地上传”和“素材库”两个来源。
- 导入动作发生在具体资产卡内，因此目标资产编号天然明确，不再增加二次选择。

### 绑定规则

- 只允许导入图片。
- 本地图片写入现有图片存储；素材库图片复用现有素材选择器。
- 导入结果通过现有工作流图片补丁写回当前资产，保留原资产编号、描述和生图提示词。
- 每次导入形成新的图片版本，历史版本不删除，可在资产卡版本选择器中切换。
- 导入成功后，该资产视为图片已绑定；全部必要资产完成后自动解锁提示词与视频生产依赖。

## 分镜生产页面

### 分镜来源

- 不再用通用默认值伪装为已生成分镜。
- `shot-breakdown` Skill 必须从当前剧本输出每个镜头的原文片段、景别、机位、运镜、动作、表演与情绪、对白或旁白、时长和连续方式。
- Skill 产物成功后直接同步为可编辑分镜队列，不再要求用户先审核原始 JSON、再批准、再载入。
- 产物校验失败时保留旧分镜，显示失败原因和“重新生成分镜”，不退回空白手填状态。

### 页面顺序

选中镜头后的主区顺序固定为：

1. 对应原剧本。
2. 结构化分镜。
3. 参考图定义与绑定。
4. 多模态视频提示词。
5. 已绑定参考摘要。

移除单独的镜头编号、场景名和上一镜 / 下一镜摘要卡。镜头切换由左侧分镜队列承担。

### 分镜编辑

- Skill 草稿可以逐字段修改。
- “保存分镜”继续保留，用于保存未确认草稿。
- “确认分镜”保存当前改动并冻结本次提示词输入基线。
- 分镜确认后再次修改，会把已有提示词标记为过期，必须重新生成或重新确认。

## 参考图定义与绑定

参考图面板位于结构化分镜之后、视频提示词之前，并按当前镜头保存选择结果。

### 来源

- 当前集已经生成或导入的资产图片。
- 本地图片上传。
- 我的素材或服务器素材库。
- 系统产生的上一镜尾帧连续性参考。

本地上传的镜头参考图写入“我的素材”并记录当前项目、分集、镜头和定义类型；从素材库选取时保留来源素材编号和版本引用，不复制成无来源的临时图片。

### 定义类型

每张手动导入的参考图必须选择一种用途：

- 角色基准图：绑定角色资产编号。
- 角色马甲：绑定父角色资产编号，并记录马甲名称或变体编号。
- 场景图：绑定场景资产编号。
- 道具图：绑定道具资产编号。
- 站位 / 构图图：绑定当前镜头，不要求资产编号。
- 上一镜尾帧连续性参考：绑定来源镜头和尾帧版本。

角色、马甲、场景和道具的候选项来自当前集资产卡。站位图只影响当前镜头，不写成角色或场景资产。

上一镜尾帧始终使用 `continuity_reference`：它只帮助模型理解故事从上一画面之后继续，保持场景和角色一致；不得标记为首帧，不要求第一帧复刻，也不用于重新诠释画风或材质。

### 选择限制

- 每个视频提示词任务最多提交 9 张参考图。
- 有连续性尾帧时，为它保留一个参考位，其他资产图最多 8 张。
- 面板清楚显示图片来源、定义、绑定对象、版本和是否入选本镜。
- 图片文件丢失、定义不完整或绑定对象失效时阻止生成提示词，并指出具体图片。

## 提示词编辑

- 参考图选择完成并确认分镜后，才可生成提示词。
- 输入包含当前剧本片段、已确认结构化分镜、已定义参考图和连续性参考。
- 文本框继续使用现有延迟自动保存机制。
- 移除显式“保存”按钮，只保留保存状态和“确认提示词”。
- 切换镜头前先完成正在排队的自动保存；保存失败时阻止切换并给出重试提示。

## 状态与错误处理

- Skill 任务、资产生图和视频生成都进入后台任务，不阻塞整个页面。
- 状态显示具体对象和动作，例如“资产提取中”“分镜提取失败”“提示词自动保存失败”。
- 本地上传或素材库导入单项失败时不影响其他资产或参考图。
- 旧剧本版本、旧分镜版本或旧参考图版本仍保留，但明确显示“已过期”，不得静默用于新提示词。
- 不增加无业务价值的确认弹窗；只有产生真实图片或视频费用的动作保留费用确认。

## 验收标准

1. 项目中心可编辑并保存原剧本，刷新后内容仍存在。
2. 视频工作流剧本页可分别选择资产提取与分镜提取 Skill；后台 Agent Run 记录实际选择的版本快照。
3. 资产提取和分镜提取可以并行，分镜提取不依赖资产图片完成。
4. 分镜队列来自 Skill 产物，不使用通用默认字段冒充生成结果。
5. 资产卡能从本地或素材库导入图片，并绑定原资产编号、增加版本记录。
6. 参考图位于结构化分镜之后，支持六种定义和对应绑定规则。
7. 镜头摘要卡消失，左侧队列仍能切换镜头。
8. 提示词修改自动保存，界面没有“保存”按钮；确认提示词仍可用。
9. 连续性尾帧只作为普通剧情连续性参考提交，不作为首帧。
10. 刷新、切换镜头和切换工作流阶段后，剧本、已冻结 Skill 版本、分镜修改、参考绑定和版本状态保持一致。

## 测试策略

- 后端：Skill 版本可见性、阶段匹配、发布状态、运行时覆盖、默认回退和冻结快照测试。
- 前端纯逻辑：剧本过期判定、分镜产物同步、参考图定义与绑定、9 图限制、连续性参考保留位和提示词输入摘要测试。
- 组件交互：本地 / 素材库导入、资产版本增加、参考图定义校验、提示词自动保存与镜头切换阻断测试。
- 浏览器验收：从修改剧本开始，依次完成信息提取、资产导入、分镜修改、参考图定义、提示词确认和最小视频生成，循环修正阻塞或多余步骤。

## 非目标

- 不调整画布页面及画布节点模型。
- 不修改前台或后台模型配置方式。
- 不在视频工作流内提供 Skill 文件编辑与发布；这里只选择已发布版本。
- 不把上一镜尾帧升级为首帧控制图。
