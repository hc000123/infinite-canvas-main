# 独立提示词库与文件夹设计

## 目标

把 `/prompts` 从“配方启用面板”调整为独立的提示词资料库。顶部导航直接进入该页面；页面同时展示后端维护的公司内置提示词与保存在浏览器本地的个人提示词，并允许用文件夹整理个人内容。

## 信息架构

- 左侧资料树固定包含“全部提示词”“公司内置”“我的提示词”，个人文件夹显示在“我的提示词”下方。
- 右侧为统一列表，提供搜索、图片/视频类型筛选与新建提示词；当前资料树节点决定内容来源或个人文件夹。
- 公司内置提示词只读，可查看、复制或复制到“我的提示词”。
- 个人提示词可新建、编辑、复制、移动文件夹和删除。
- 文件夹可新建、重命名、删除；删除文件夹时其中的提示词回到“未分类”，不删除提示词。
- 全局配置弹窗只保留模型、密钥和渠道相关设置，不再出现重复的提示词入口。

## 数据边界

- 公司内置提示词继续读取 `/api/prompts`，不改变后台标准与画布配方的现有数据路径。
- 个人提示词与文件夹使用独立 Zustand store，并通过项目既有 `localForageStorage` 持久化。
- 个人提示词转换为现有 `Prompt` 结构后复用详情弹窗，避免建立第二套展示协议。

## 交互原则

- 页面默认显示全部来源，用户无需选择项目或先切换“当前生效”。
- 卡片保持紧凑，以文本为主；无预览图时不预留大图区域。
- 删除个人提示词和文件夹需二次确认；其他操作即时保存。
