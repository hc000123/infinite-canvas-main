# 视频工作流资产卡片低确认模式设计

## 目标

把“资产设计”从需要逐阶段批准的 Agent 审核页，改成面向制作结果的资产卡片台。系统自动完成资产提取、逐资产提示词生成和卡片绑定；用户只检查卡片内容，必要时编辑，并在真实生图前确认一次。

本次只调整视频工作流的资产设计阶段，不改画布，也不改后台模型设置。

## 用户主路径

1. 用户进入资产设计阶段。
2. 如果当前剧本还没有对应资产结果，系统自动启动资产提取。
3. 资产提取通过质量门后，系统自动批准并启动逐资产生图提示词任务。
4. 提示词任务通过质量门后，系统自动批准并将结果幂等写入本项目素材库，形成资产卡片。
5. 用户直接检查卡片的资产描述、剧本证据、提示词和预览图；有误时就地修改。
6. 用户选择单张、若干张或全部待生成资产，点击生成。
7. 系统只弹出一次费用确认。确认后自动完成图片生成、版本归档和逻辑资产绑定，不再出现“批准产物”或“确认写入”步骤。
8. 已有完整卡片结果时再次进入页面，直接展示卡片，不重复运行任务。

如果自动任务失败或质量门未通过，页面显示可理解的失败原因和“重新提取”或“重新生成提示词”动作，不要求用户处理底层审核状态。

## 页面结构

采用已确认的双列制作卡片布局。

### 顶部状态区

- 展示资产总数、待生成数、已生成数和自动整理状态。
- 提供“重新提取”次级动作。
- 提供“确认生成 N 项”主动作。
- 不展示执行尝试、Artifact Hash、批准、退回、写入等内部 Agent 控制项。

### 分类

一级分类只有：

- 全部
- 角色
- 场景
- 道具

分类标签显示数量，切换只过滤卡片，不改变资产绑定关系。

`costume` 类型不作为一级分类。服装、发型、妆容、年龄阶段、受伤状态等角色外观变化，统一显示为对应角色的“马甲”。

### 资产卡片

每张卡片包含：

- 稳定逻辑编号和名称。
- 类型、生成状态和当前版本。
- 剧本原文证据。
- 可编辑资产描述。
- 可编辑生图提示词。
- 当前图片预览；未生成时显示清晰空态。
- 图片工作台入口。
- 单卡生成或重新生成按钮。
- 生成选择开关，供顶部批量生成使用。

编辑采用卡片内就地编辑或轻量编辑弹层，保存后立即写回同一资产记录，不产生新的逻辑资产编号。

### 原图查看

点击预览图或“放大原图”打开图片预览层。预览层支持：

- 按原始分辨率查看。
- 缩放和拖拽。
- 关闭预览。
- 下载原图。
- 查看该资产的历史图片版本。

优先复用 Ant Design `Image.PreviewGroup` 和现有资产版本数据，不另造图片查看器。

## 角色与马甲关系

角色主体使用稳定编号，例如 `CHAR-001`。角色外观马甲仍以独立、可追溯的资产条目保存，但通过以下字段绑定到角色主体：

- `parentLogicalAssetId`: 父角色编号，例如 `CHAR-001`。
- `variantType`: `costume`、`hair`、`makeup`、`age`、`injury` 或 `other`。
- `variantName`: 面向用户的马甲名称，例如“旧棉衣”“病中状态”。

为了沿用现有质量门和稳定编号协议，角色马甲的底层编号继续使用 `COSTUME-xxx`。界面将其折叠进角色卡，不在顶层显示为服化分类。镜头生产引用马甲时，同时保留父角色编号和马甲资产编号，确保角色身份与具体外观都可追溯。

找不到明确父角色的马甲不能静默挂错角色：质量门将其标记为问题，卡片区显示“待关联角色”，允许用户选择角色后再生成。

## 数据与持久化

### 工作流产物

资产提取和提示词产物继续使用现有 `items[]`，新增可选字段：

- `parentLogicalAssetId`
- `variantType`
- `variantName`

角色、场景和道具的现有字段不变：`logicalAssetId`、`kind`、`name`、`scriptEvidence`、`description`、`imagePrompt` 和 `status`。

### 本地素材绑定

卡片仍复用 `useAssetStore`，不增加另一套业务列表。每条卡片通过现有作用域键保持幂等：

`projectId:episodeId:logicalAssetId`

工作流元数据新增父角色与马甲字段。自动同步只更新工作流负责的标题、证据、描述、提示词和关系字段；已有图片、历史版本、用户上传结果和其他素材元数据必须保留。

卡片编辑直接更新素材记录中的 `originalWorkflow.description`、`originalWorkflow.imagePrompt` 和可读文本内容。重新运行自动整理时，不覆盖用户已修改且标记为人工编辑的字段；新模型结果作为可选择更新呈现。

## 自动串行与确认策略

资产设计内部仍保留两个可独立换 Skill 的阶段：

- `asset-extraction`
- `asset-image-prompt`

界面不再暴露两套阶段审核面板。自动控制器负责：

- 首次缺结果时启动提取。
- 质量门通过后自动批准提取结果。
- 自动启动提示词任务。
- 提示词质量门通过后自动批准并同步为卡片。
- 使用现有幂等键避免刷新或重复渲染造成重复任务和重复资产。

质量门仍然生效，只是正常结果不再要求人工点击批准。质量门失败时停止自动链，并显示问题与重试入口。

真实图片生成是唯一必须确认的步骤。单卡生成和批量生成都只显示一次确认弹窗，内容包括图片数量、模型和费用提醒。用户确认后不再询问写入或绑定。

## 生成行为

- 单卡生成只生成当前卡片或当前角色马甲。
- 批量生成默认选择所有尚未生成的可用卡片；用户可取消个别卡片。
- 单张失败不取消其他任务。
- 每张成功图片立即回写同一素材记录，保存版本历史并更新卡片预览。
- 重新生成保留旧版本，不替换逻辑资产编号。
- 角色马甲生成结果归入父角色卡，并可作为镜头生产中的具体角色外观参考。

## 错误与恢复

- 自动提取失败：显示原因和“重新提取”，已存在的卡片不删除。
- 提示词生成失败：保留提取结果，显示“重新生成提示词”。
- 部分条目无提示词：卡片可编辑，但生成按钮禁用并说明原因。
- 马甲缺少父角色：显示“待关联角色”，完成关联后允许生成。
- 图片生成部分失败：成功卡片正常回写，失败卡片保留错误和重试按钮。
- 页面刷新：从远端工作流记录和本地素材库恢复，不重复执行已完成动作。

## 测试与验收

### 自动流程

- 首次进入资产设计后，提取与提示词阶段自动串行完成。
- 正常质量门通过时不出现批准、退回或确认写入按钮。
- 刷新页面不会重复启动任务或创建重复素材。
- 质量门失败时自动流程停止并显示可操作错误。

### 卡片与分类

- 提取结果按角色、场景、道具正确分类。
- `costume` 及其他外观变化归入正确角色的马甲列表。
- 所有卡片都有稳定编号、证据、描述、提示词和生成状态。
- 编辑描述或提示词后刷新仍保留。

### 图片

- 未生成卡片显示空态。
- 已生成卡片显示预览图，点击可放大原图。
- 单卡生成只出现一次费用确认，并自动绑定结果。
- 批量生成只出现一次费用确认；部分失败不会回滚成功结果。
- 重新生成增加版本且保留旧版本。

### 镜头衔接

- 镜头生产能读取角色主体、具体马甲、场景和道具图片。
- 选择角色马甲后，同时保留父角色和马甲的绑定信息。

## 不在本次范围

- 不改画布。
- 不改后台模型选择与渠道设置。
- 不自动触发付费图片生成。
- 不删除现有工作流 Skill、质量门或任务记录。
- 不改变视频生成和尾帧连续性规则。
