# 生成结果自动回写资产设计

## 目标

生成成功的图片和视频继续自动进入项目缓存；只有从明确的角色、场景或道具资产上下文发起的生成，才自动回写到对应资产。普通画布生成不得自动创建正式资产。

## 行为边界

- 资产工作台生成图片：结果进入缓存，并加入当前主体、当前形态的候选图。
- 正式资产修改或再生成：结果进入缓存，并创建继承原资产绑定的新版本；新版本设为当前版本。
- 图片 Brief、资产拆解项或设定库条目发起的生成：结果进入缓存，并继续回写对应结果引用；只有上下文含有稳定资产身份时才写入正式资产记录。
- 分镜或镜头组发起的视频生成：结果进入缓存，并继续作为对应镜头结果，不归入角色、场景或道具主体。
- 普通画布图片、视频生成：只进入缓存，不创建资产记录，也不弹出资产归类窗口。

## 数据流

生成入口在提交任务时保留稳定来源信息，包括源资产 ID、主体 ID、形态 ID以及 Brief、设定或镜头 ID。生成完成后先写缓存，再由统一判定函数决定是否需要资产回写：

1. 没有明确业务来源时结束，不调用资产 store。
2. 资产工作台结果写入候选图集合。
3. 正式资产修订结果复制原 `assetBinding`，创建新媒体版本并更新形态当前资产。
4. Brief、设定和镜头结果沿用现有结果引用写入路径。

归属判断只读取稳定 ID，不根据标题、提示词或标签猜测。

## 去重与失败处理

- 正式资产继续通过媒体指纹去重，重复完成回调不会创建相同版本。
- 候选图以存储键或来源媒体标识去重，避免刷新、恢复或重试造成重复候选。
- 缓存成功、资产回写失败时，生成任务仍视为成功，并提示“已缓存，回写资产失败”。
- 缓存失败不阻止本地生成结果展示，沿用现有缓存重试机制。

## 验收范围

- 普通画布图片和视频生成后只增加缓存，不增加资产记录。
- 从资产工作台生成的图片自动出现在对应形态候选区。
- 从正式资产发起修订后自动产生绑定一致的新版本并成为当前版本。
- Brief、设定、分镜和镜头组已有结果引用不回退。
- 重复完成同一结果不会生成重复资产或候选。
