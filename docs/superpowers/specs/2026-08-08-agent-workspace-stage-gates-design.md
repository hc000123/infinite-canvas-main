# 项目 Agent 工作区与阶段闸门设计规格

## 目标

在全局顶部导航增加“Agent”入口，把现有分散在项目、单集生产工作台、Workflow Run、Skill、Invocation 和资产工作台中的能力整理为一个跨项目生产总控台。用户可以切换项目，查看每个项目与分集当前运行到哪个阶段、哪些结果等待审核、哪些任务正在执行或失败，并从总控台继续进入既有单集工作台完成编辑与生产。

Agent 采用阶段闸门模式：阶段内部可以自动执行，阶段之间必须由用户确认。视频生成始终由用户手动启动，避免未经确认消耗算力。

本功能不是新增自由聊天机器人，也不重建 Agent / Workflow 运行引擎。现有 Workflow Run 是运行状态的唯一事实来源，现有单集工作台继续承担剧本、资产、分镜、提示词和视频的专业编辑操作。

## 调研结论

飞书“Seedance2.0 智能创作模式”的核心不是一次性自动生成，而是一条有人工校正节点的项目生产链：

1. 上传并整理剧本。
2. 导演 Agent 自动提取角色、场景和道具。
3. 用户对提取结果进行新增、删除、改名和修正。
4. 资产结果继续被分镜和视频生成复用。
5. 生成视频镜头并进入预览。

值得复用的是“项目上下文、阶段进度、人工修正、结果下钻”四个关系。现有系统已经具备更完整的运行底座：

- `WorkflowRun`、`WorkflowStageRun`、`WorkflowArtifact` 和事件流。
- 阶段启动、取消、重试、审核、应用及质量门。
- Skill 版本选择和 Invocation 快照。
- 单集 Workflow 工作台中的剧本、资产、镜头、最终提示词和视频控制台。
- 本地项目、分集、资产、视频生产包与画布数据。

因此新页面只负责跨项目汇总、阶段闸门和入口收口，不复制已有编辑器或运行状态。

## 信息架构

### 顶部入口

在全局文字导航的“项目”和“画布”之间增加“Agent”：

```text
项目 / Agent / 画布 / 生图 / 提示词 / 资产 / 缓存
```

入口地址为 `/agent`。从项目或单集进入 Agent 时可携带 `projectId` 和 `episodeId`，但没有参数时默认展示所有项目。

### Agent 总控台 `/agent`

页面分为三层：

1. 顶部项目工具栏。
2. 项目或分集进度概览。
3. 当前选中分集的阶段链与最近运行。

顶部工具栏包含：

- “所有项目 / 具体项目”切换。
- 项目名称搜索。
- 状态筛选：全部、运行中、待审核、阻塞、失败、已完成。
- 待审核数量、运行中数量和异常数量汇总。

“所有项目”视角展示项目卡。项目卡包含项目名、总体进度、分集数量、正在运行的阶段、待审核数量、阻塞或失败提示、最近更新时间，以及“查看 Agent”入口。

选择具体项目后，展示该项目下的分集列表。每个分集展示阶段进度、当前阶段、最近运行状态和“继续生产”入口。选择分集后，在同页展开阶段详情；专业编辑仍跳转到 `/projects/[projectId]/episodes/[episodeId]/workflow`。

## 阶段模型

Agent 总控台统一展示六个阶段：

1. 剧本确认。
2. 资产解析。
3. 资产生产。
4. 结构化分镜。
5. 最终提示词。
6. 视频生成与预览。

其中“资产生产”允许跳过或部分完成；缺少图片不阻止后续阶段。阶段展示状态统一映射为：

- 未开始
- 可开始
- 运行中
- 待审核
- 已批准
- 已应用
- 有警告
- 已阻塞
- 失败
- 已取消

总体进度按阶段闸门完成度计算，不按后台任务数量计算。可选资产未生成只记为警告，不降低已批准阶段的完成状态。

## 阶段闸门

### 1. 剧本确认

输入为项目分集的原始剧本或已优化生产稿。用户确认不可变剧本快照后，才能启动资产解析。剧本在后续被修改时，不覆盖已经运行的 Workflow Run；用户需要明确创建基于新剧本快照的新运行版本。

### 2. 资产解析

Agent 从剧本中识别角色、场景、道具和站位，输出“资产槽位”，而不是立即创建正式资产。

用户可以在审核时：

- 新增漏识别槽位。
- 删除误识别槽位。
- 重命名槽位。
- 合并重复槽位。
- 将一个错误合并的槽位拆分为多个槽位。
- 修改类别、描述和适用范围。
- 标记为忽略。
- 绑定已有正式资产。

资产解析以用户点击批准为完成条件，不要求所有槽位都已经生成图片。

### 3. 资产生产

已批准的资产槽位可以进入资产工作台生成或上传候选图，也可以继续保持文字占位。该阶段支持逐个生产、批量生产和稍后补齐。

资产生产不作为结构化分镜的硬阻塞条件。用户可以在以下状态下继续：

- 已绑定正式资产。
- 已有候选图但尚未转正。
- 只有文字描述的占位符。
- 已忽略。

只有用户主动生成或绑定正式资产后，内容才进入正式资产库。

### 4. 结构化分镜

结构化分镜是镜头方案，不是最终模型提示词。每个镜头包含：

- 镜头顺序与时长。
- 场景、叙事目标与剧情节拍。
- 景别、机位、运镜和构图。
- 人物动作、表演和台词。
- 角色、场景、道具及站位槽位引用。
- 连续性要求和风险提示。

用户可以新增、删除、拆分、合并和排序镜头，也可以调整节奏、台词和槽位引用。结构化分镜批准后才允许生成最终提示词。

### 5. 最终提示词

最终提示词由已批准的单个结构化分镜生成，是面向具体视频模型的执行稿。它包含 Seedance 等模型要求的时间轴、镜头语言、动作、表演、声音和生成约束。

引用转换规则：

- 已绑定正式图片的槽位转换为结构化 `@图片` 引用。
- 只有文字占位的槽位转换为名称和外观描述，不伪造图片引用。
- 已忽略槽位不进入提示词。
- 后续绑定正式资产时，根据稳定槽位 ID 更新引用候选，但不静默修改已经批准的提示词；用户需要明确重新生成或接受更新。

最终提示词允许逐镜人工修改、重新生成和批准。只有已批准的提示词可以进入视频生成。

### 6. 视频生成与预览

视频生成始终手动启动。启动前展示模型、预计算力、参考图片、占位符警告和提示词版本。用户可以只生成单镜，也可以批量启动全部已批准镜头。

失败只影响对应镜头，不回滚已经批准的剧本、资产槽位、分镜或提示词。预览区汇总成功片段、失败任务、待生成镜头和连续性风险。

## 资产槽位与占位符

### 数据身份

资产槽位使用稳定 `slotId`，在一次 Workflow Run 内不会因改名或后续绑定资产而改变。建议结构：

```ts
type AgentAssetSlot = {
  slotId: string;
  category: "character" | "scene" | "prop" | "blocking";
  name: string;
  description: string;
  status: "placeholder" | "candidate" | "bound" | "ignored";
  sourceSceneIds: string[];
  sourceEvidence: string[];
  subjectId?: string;
  variantId?: string;
  assetId?: string;
  candidateId?: string;
};
```

槽位保存在资产解析阶段的 `WorkflowArtifact` 中。用户修正产生新的 Artifact 版本，保留原始提取结果和审核记录。不新增一套独立数据库表。

### 与正式资产库的边界

- `placeholder` 只存在于 Agent 流程，不进入正式资产库。
- `candidate` 指向资产工作台候选，不视为正式资产。
- `bound` 指向现有正式资产、主体和形态。
- `ignored` 保留审核痕迹，但不参与后续提示词。

删除或忽略槽位不会删除正式资产。正式资产被删除后，槽位回退为 `placeholder` 并保留文字描述，不使后续分镜失效。

### 进度呈现

资产阶段不显示单一“完整 / 不完整”，改为：

```text
已识别 12 · 已绑定 7 · 候选 2 · 占位 2 · 已忽略 1
```

占位数量是警告信息，不是阻断条件。

## 运行与数据流

### 唯一事实来源

- 后端 Workflow Run 保存运行、阶段、产物、审核和事件状态。
- 本地项目与分集 Store 提供名称、排序、剧本和本地生产数据。
- 正式资产继续由现有资产 Store 保存。
- Agent 总控台不新增另一套进度 Store，只派生显示数据和少量页面筛选状态。

### 跨项目查询

现有接口只支持创建、读取和轮询单个 Workflow Run。总控台需要增加只读列表接口：

```text
GET /api/v1/workflow-runs
  ?projectId=
  &episodeId=
  &status=
  &page=
  &pageSize=
```

接口返回运行头、各阶段最新状态、待审核数量、警告数量和最近更新时间。列表不返回完整剧本快照或大体积 Artifact 内容；选择分集后再读取现有详情接口。

列表查询继续限制为当前用户可访问的运行。现阶段项目主要保存在浏览器本地，因此页面使用本地项目清单与后端返回的 `projectId`、`episodeId` 合并显示；后端未知的本地项目不创建运行记录，只显示“尚未开始”。

### 进入单集工作台

Agent 总控台中的“继续生产”跳转至现有单集 Workflow 页面，并携带当前阶段：

```text
/projects/[projectId]/episodes/[episodeId]/workflow?stage=...
```

总控台不复制资产编辑、分镜编辑、最终提示词编辑或视频控制台。

## 页面交互

视觉延续当前紧凑、低视觉重量的 studio 工作区：

- 顶部仍使用统一文字导航。
- 项目卡以进度、异常和待审核状态为主要视觉信息，不使用装饰性大图。
- 阶段链使用清晰的横向步骤条；窄屏变为纵向时间线。
- 运行中使用轻量动态状态，避免持续大面积动画。
- 阻塞、失败、待审核和占位警告使用现有主题语义色。

默认视图优先回答三个问题：

1. 哪个项目正在运行？
2. 哪个阶段需要我处理？
3. 下一步会进入哪里？

## 错误与边界处理

- 项目存在但没有分集：显示“请先创建或导入分集”，不创建 Workflow Run。
- 分集没有剧本：剧本阶段显示阻塞，并提供返回项目入口。
- 后端不可用：保留本地项目和分集列表，远程进度显示暂不可用。
- 同一分集存在多个剧本快照运行：默认展示最近更新的运行，并允许查看历史版本。
- 阶段运行失败：允许重试当前阶段，不自动推进。
- 阶段待审核：禁止启动依赖该产物的下一阶段。
- 资产全部为占位：允许进入分镜和最终提示词，但在视频启动前显示明确警告。
- 正式资产引用失效：回退到槽位文字描述，不删除结构化分镜。
- 部分视频失败：成功片段保留，失败镜头单独重试。

## 权限与算力

- 普通用户只能查看和运行自己可访问项目中的 Agent。
- 阶段预检继续沿用现有 Skill、模型和算力检查。
- 剧本、资产解析、分镜和最终提示词阶段在确认前展示预估消耗。
- 视频生成必须再次手动确认模型、镜头数量和预计算力。
- 只读查看进度不创建任务、不调用模型、不扣除算力。

## 测试与验收

### 领域与接口

- Workflow Run 列表只能返回当前用户运行。
- 项目、分集、状态和分页筛选正确。
- 列表阶段摘要与详情最新阶段一致。
- 资产槽位增删改、合并、拆分和绑定保持稳定 `slotId`。
- 资产槽位修正生成新 Artifact 版本，不覆盖原始提取结果。
- 占位槽位不创建正式资产。
- 正式资产删除后槽位正确回退为占位状态。
- 占位槽位不会阻止结构化分镜。
- 未批准分镜不能生成最终提示词。
- 未批准提示词不能启动视频生成。

### 页面

- 顶部导航可进入 Agent，当前栏目高亮正确。
- “所有项目”能看到未开始、运行中、待审核、失败和已完成项目。
- 可切换项目并查看各分集进度。
- 点击待审核阶段进入正确的单集工作台和阶段。
- 资产统计能区分已绑定、候选、占位和忽略。
- 只有占位符时仍可批准资产阶段并生成结构化分镜。
- 结构化分镜与最终提示词在界面和状态上明确分离。
- 视频生成前必须出现手动启动动作和算力信息。
- 浅色、深色与窄屏布局均可使用。

## 实施范围

本次包含：

- 顶部“Agent”入口。
- `/agent` 跨项目总控台。
- Workflow Run 跨项目列表接口与阶段摘要。
- 项目、分集和阶段进度展示。
- 阶段闸门与现有单集工作台下钻。
- 资产槽位、占位符及人工修正版本。
- 结构化分镜与最终提示词的明确边界。

本次不包含：

- 自由聊天 Agent。
- 新的 Agent / Workflow 执行引擎。
- 未经审核自动执行完整生产链。
- 自动启动视频生成。
- 团队协作、项目成员分工或云端项目同步。
- 复制现有资产、分镜和视频编辑器到 Agent 总控台。
