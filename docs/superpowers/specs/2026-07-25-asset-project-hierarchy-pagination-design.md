# 素材库项目层级筛选与完整项目分页设计

## 目标

纠正素材库把“项目”和“工作流 / 画布”当作并列、互斥筛选的模型。素材库应先按创作项目收口，再在该项目内部查看全部来源、工作流来源或画布来源；结果分页不得把同一个项目拆到两个页面。

本设计取代旧设计中“工作流项目与画布互斥选择”的交互，但保留已经实现的素材画布来源识别能力。

## 业务层级

素材库使用以下层级：

1. `项目`：顶层实体，对应 `CreativeProject`。
2. `来源范围`：当前项目下的 `全部`、`工作流`、`画布`。
3. `具体画布`：只有选择“画布”范围时出现，只列出当前项目绑定的画布。
4. `集数`：工作流范围继续复用现有集数筛选，不新增第二套工作流实例选择器。

画布与项目的绑定同时读取 `CreativeProject.canvasIds` 和 `CanvasProject.projectId`，统一使用项目已有的画布归属计算。没有绑定项目的旧画布进入“未归属项目”，不混入任意正式项目。

## 筛选交互

素材库顶部“项目”区域调整为紧凑级联筛选：

- 项目选择器显示创作项目名称，不再使用“工作流项目”文案。
- 未选择项目时，来源范围保持“全部”，具体画布选择器不显示。
- 选择项目后，显示 `全部 / 工作流 / 画布` 三个低视觉重量的范围标签。
- 选择“全部”时，显示该项目内的工作流素材、画布素材及项目共享素材。
- 选择“工作流”时，只显示带有当前项目工作流来源或项目工作流引用关系的素材；需要进一步缩小时使用现有集数筛选。
- 选择“画布”时，显示具体画布选择器；选择器只列当前项目绑定的画布。未选择具体画布时显示该项目全部画布素材，选择后只显示该画布素材。
- 切换项目时清除旧项目的具体画布、集数、分镜组、项目库和引用版本条件，避免残留条件产生空结果。
- 清除项目时同时恢复来源范围为“全部”，并清除所有项目子筛选。

不再允许选择画布时清空项目。项目始终是工作流和画布筛选的父级上下文。

## 项目与来源匹配

### 项目归属

一个素材满足下列任一条件时，视为属于所选项目：

- 素材位于该项目的素材文件夹；
- 素材的项目素材库记录包含该项目 ID；
- 素材生成记录、`canvasSource` 或 `originalWorkflow` 中的项目 ID 等于该项目 ID；
- 素材被该项目的设定、分镜或生产数据引用；
- 素材来自绑定到该项目的画布。

项目匹配集中在纯函数中，避免页面组件分别猜测素材归属。一个素材具有多条合法来源时可以同时属于多个来源视图，但在同一结果列表中只展示一次。

### 工作流来源

工作流范围识别项目工作流生成、导入或引用的素材，包括 `originalWorkflow`、工作流生成记录、生产包和项目工作流引用。仅仅位于项目文件夹但没有工作流或画布来源的共享素材仍保留在“全部”范围，不强行归类为工作流。

### 画布来源

画布范围沿用现有三类匹配：

- `metadata.canvasLibraries` 中的画布 ID；
- 任一生成记录中的 `canvasId`；
- `metadata.canvasSource.canvasId`。

画布必须先属于当前项目，具体画布筛选才可生效。素材同时具有工作流和画布来源时，可在两个来源范围内查询到。

## 分组与分页

当前实现先按固定 30 条切割平铺素材，再按项目分组，因此同一项目会被拆到不同页面，项目标题中的数量也只代表当前页。

素材类型分组只读取明确的工作流类型 metadata 或素材自身 `kind`，显示“图片 / 视频 / 音频 / 文本”等真实类型。不得再把素材名称最后一段作为任意类型；`画布名称-节点001-v3` 中的 `v3` 只属于名称和版本信息，不得生成 `v3` 分组。旧工作流素材需要“角色 / 场景 / 道具”等细分时，继续读取其明确的 `originalWorkflow.type`。

调整后的规则：

- 先完成筛选和名称排序，再构建完整项目分组。
- “全部项目”视图按完整项目组分页，不拆分项目。以 30 个素材作为目标容量：按项目顺序依次装入当前页，加入下一个项目会超过目标容量时换页；单个项目超过 30 个素材时独占一页并完整展示。
- 已选择具体项目时关闭全局素材分页，完整显示该项目的筛选结果；素材数量较多时通过页面滚动浏览，不把同一项目隐藏到下一页。
- 项目标题始终显示该筛选条件下的项目真实素材总数，不显示页内局部数量。
- 设定项与素材使用同一项目组，不出现设定在第一页、同项目素材在第二页的情况。

分页控件直接按计算出的项目页数量切换，不再把素材总数交给固定条数分页器；项目级分页不提供 30 / 60 / 100 条切换。用户改变项目、来源范围、具体画布、集数、类型、收藏、关键词或排序时回到第一页。

## 状态与职责

- `useAssetPageQuery` 管理顶层项目、来源范围和具体画布状态，并生成当前项目的画布选项。
- 项目—画布关系复用 `canvasIdsForCreativeProject`，不新增重复绑定字段。
- `asset-page-filters.ts` 或同目录纯工具负责项目归属、工作流来源、画布来源及完整项目分页计算。
- `AssetFilterPanel` 只展示级联控件和触发筛选动作，不直接解析素材 metadata。
- `AssetResultsSection` 接收已经完整分组的结果，渲染真实数量和项目级分页。

筛选状态仍是页面会话状态；项目、画布和素材继续保存在浏览器本地，不新增云同步承诺。

## 空状态与异常边界

- 所选项目没有绑定画布时，“画布”范围仍可显示，但具体画布选择器禁用并提示“当前项目没有画布”。
- 已选画布被删除或解除项目绑定后，自动清除具体画布条件并保留当前项目。
- 旧素材只有画布 ID、没有项目 ID 时，通过画布绑定关系推导项目；无法推导时进入“未归属项目”。
- 删除项目只解除归属关系，不删除素材；相关素材随后进入其他合法项目或“未归属项目”。
- 筛选结果为空时明确显示当前项目和来源范围，不回退展示其他项目素材。

## 验证

### 纯函数测试

- 项目归属同时覆盖项目文件夹、项目库、工作流 metadata、画布 metadata、项目引用和绑定画布。
- 项目下画布选项只包含 `canvasIds` 或 `projectId` 匹配的画布。
- 工作流、画布和全部来源范围能正确取交集，混合来源素材不重复。
- 37 个同项目素材不会被拆成 30 + 7；多个项目分页时保持项目组完整。
- 项目标题数量为完整筛选结果数量，而不是当前页切片数量。
- `画布名称-节点027-v3` 按素材真实类型进入“视频”或“图片”分组，不出现 `v3` 分组。

### 页面验证

- 选择项目后，画布选择器只显示该项目画布；切换项目不会残留旧画布。
- “全部 / 工作流 / 画布”与类型、收藏、关键词、集数和名称排序叠加正确。
- 单个项目超过 30 个素材时仍在同一项目页面连续显示。
- 全部项目视图翻页时，同一项目不会同时出现在相邻两页。
- 未归属画布和旧来源素材仍可找到，不会混入错误项目。
- 新命名素材的外层类型分组保持稳定，不随 `v1 / v2 / v3` 改变。

## 非目标

- 不新增云端项目或素材同步。
- 不改变项目、画布、工作流的持久化结构。
- 不支持一次选择多个项目或多个具体画布。
- 不在本轮新增具体工作流运行实例选择器；工作流的细分继续使用现有集数筛选。
- 不修改素材编辑、下载、收藏、审核、导出和画布插入行为。
