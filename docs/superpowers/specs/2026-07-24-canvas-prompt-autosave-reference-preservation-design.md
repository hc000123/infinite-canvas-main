# 画布放大提示词自动保存与生成后引用保留设计

## 目标

放大编辑节点提示词时实时保存，不再要求点击“保存”；图片、视频生成完成后继续显示生成前提示词中的 `@` 图片缩略图及其他媒体引用。

## 范围

- 图片、视频和文本节点的“展开编辑提示词”弹窗改为实时保存。
- 生成配置节点的节点提示词已经实时保存，保持现有行为。
- 首次生成、新版本生成和由文本 / 生成配置节点派生的图片、视频结果均保留结构化提示词文档。
- 新生成结果只继承本次实际使用的直接上游图片、视频、音频连线，不复制上游文本连线。
- 不在结构化提示词中保存图片 data URL 或缩略图快照；预览继续读取真实上游节点。

## 放大编辑交互

普通节点的放大提示词编辑器直接调用现有 `updatePromptDocument`。每次编辑都会同步更新组件状态和画布节点的 `prompt` / `promptDocument`；弹窗移除“保存”和“取消”按钮，仅保留关闭入口。

关闭弹窗时只关闭界面，并刷新紧凑编辑器的 revision，使节点内提示词立即显示最后一次输入。关闭、遮罩点击和 Esc 均不回滚已经输入的内容。

## 生成后的引用保留

生成提交时从源节点读取当前实际编辑文档：已生成媒体优先使用 `promptDraftDocument`，未生成节点和生成配置节点使用 `promptDocument`。

该文档随生成参数进入结果节点：

- 空图片 / 空视频节点原地生成时保留当前 `promptDocument`。
- 文本或生成配置节点派生新结果时，把当前 `promptDocument` 写入结果节点。
- 已生成媒体创建新版本时继续通过 `pendingMediaVersion.promptDocument` 写入版本记录。
- 切换版本时继续由现有版本投影逻辑恢复对应的提示词文档。

## 媒体连线继承

结果节点需要能用真实连接重新构建 `@` 候选和缩略图。生成动作从源节点的直接上游连接中筛选实际参考输入对应的图片、视频、音频连接，并为新结果创建等价连接。

- 原地生成不新增连接，因为目标节点 ID 未变化。
- 新结果节点保留原有“源节点 → 结果节点”关系，同时增加实际媒体源到结果节点的直接连接。
- 批量图片结果的每个可编辑结果节点都继承实际媒体连接。
- 使用 `fromNodeId + toNodeId + handle` 去重，不产生重复连线。
- 不继承文本连接，避免结果节点再次生成时重复拼接提示词。

## 数据一致性与错误处理

- `@` 引用仍以真实节点 ID 持久化，缩略图始终来自当前连接的上游节点。
- 上游媒体被删除或断线后，引用继续显示失效状态并阻止生成，不自动绑定其他素材。
- 没有结构化文档的旧提示词继续按纯文本显示，不新增旧数据迁移逻辑。
- 生成失败时沿用现有回滚逻辑，保留用户最后编辑的提示词草稿和结构化引用。

## 测试

- 接线测试确认放大编辑器直接使用实时更新函数，弹窗不再出现保存按钮或保存处理器。
- 生成节点纯函数测试确认图片、视频结果保留 `promptDocument`。
- 连接规划测试确认新结果只继承实际媒体连接，排除文本并去重；原地生成不重复建线。
- 媒体版本测试确认新版本和版本切换保留各自的结构化 `@` 引用。
- 页面验收覆盖普通节点、生成配置节点和文本节点派生媒体，确认生成前后缩略图保持一致。
