# 分集生产名称规范设计

## 目标

分集组合名称统一使用可直接进入素材、视频和工程文件名的安全格式，避免中点、空格和跨平台非法字符造成 Windows、macOS 或剪辑软件识别差异。

## 规则

- 集号继续强制使用 `EP01`、`EP02` 这类标准格式。
- 原始自定义标题保持不变，只在生成“生产名称”时规范化。
- 生产名称固定为 `集号-标题`，例如集号 `EP01`、标题 `-1` 输出 `EP01-1`。
- 标题经过 Unicode NFKC 规范化；连续空白或标点替换为单个短横线。
- 只保留 Unicode 字母、数字、短横线和下划线，清理 Windows/macOS 文件名禁用字符、中点、句点及其他不稳定标点。
- 清理首尾短横线和下划线；标题清理为空时使用 `未命名集数`。

## 应用范围

- 项目分集列表、原剧本和优化剧本标题。
- 素材库集数筛选与资产绑定集数选项。
- 分集主画布默认名称；修改分集标题或再次进入已有主画布时同步为当前生产名称。
- 子画布默认名称使用短横线连接，不再引入中点和空格。

## 数据边界

分集 `title` 字段继续保存用户原始输入，不做破坏性改写。所有需要稳定标识或文件名的入口统一调用一个纯函数生成生产名称，防止各页面各自拼接。
