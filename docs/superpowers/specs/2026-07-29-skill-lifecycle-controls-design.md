# Skill 名称与版本生命周期管理设计

## 目标

在管理后台 Skill 中心补齐现有后端已支持但前端缺失的管理入口：管理员可修改 Skill 名称和说明，可删除未引用草稿，可停用已发布版本，并默认隐藏已停用版本。

## 行为

- Skill 标题区提供“编辑名称”，弹窗修改 `name` 和 `summary`。
- 草稿版本提供“删除草稿”；已被工作流引用时由后端拒绝。
- 已发布版本提供“停用版本”，将状态改为 `archived`，不物理删除历史数据。
- 停用推荐版本时，后端清空当前推荐指向；管理员需选择其他已发布版本作为新推荐版。
- 版本轨道默认只显示草稿和已发布版本；“显示已停用”开关可查看历史版本。
- 已停用版本仅供查看，不能校验、评测、发布、推荐或绑定。

## 实现边界

复用现有 `UpdateOwnedSkillDefinition`、`DeleteOwnedSkillVersion` 和 `ArchiveOwnedSkillVersion`，不新增表或后端业务规则。前端仅增加 API 封装、弹窗、确认操作、状态标识和过滤开关。

## 错误处理

删除被引用草稿或无权操作时，直接显示后端的中文错误。操作成功后刷新 Skill 列表和版本详情，并选择剩余可见版本。
