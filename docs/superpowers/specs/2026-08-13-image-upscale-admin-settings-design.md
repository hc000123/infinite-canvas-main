# 图片超分后台配置设计

## 目标

在现有“后台设置 → 私有设置”中增加图片超分配置区，让管理员可以通过前端保存阿里云图片超分凭据并启停能力。画布继续复用现有 2× / 4× 云端超分、派生节点、连线和资产归档逻辑。

## 范围

- 管理员统一配置，不提供用户级 AccessKey。
- 首期只支持现有阿里云 `MakeSuperResolutionImage` 服务商。
- 配置项包括启用状态、AccessKey ID、AccessKey Secret 和可选 STS Security Token。
- 提供不上传图片、不创建超分任务的凭据连接测试。
- 不修改画布节点、连线、任务表、结果归档和重试语义。

## 后台界面

私有设置新增“图片超分”折叠卡片，沿用火山素材审核卡片的现有视觉与密钥交互：

- 标题旁显示“已开启 / 未开启”和“密钥已配置 / 密钥待配置”。
- 服务商固定显示“阿里云视觉智能开放平台”。
- 三个密钥字段使用密码输入框。
- 已保存密钥只显示状态，字段留空保存时保留原值；输入新值只覆盖对应字段。
- “测试连接”使用当前表单值；空字段自动复用后台已保存值。
- 测试成功或失败使用现有消息反馈，不改变全局保存状态。

## 数据与安全

`private` 设置新增 `imageUpscale` 对象。后台读取设置时只返回三个 `Configured` 布尔值，所有密钥字段返回空字符串。保存时由服务端恢复留空字段，前端和浏览器存储永远拿不到已保存密钥明文。

运行时优先读取后台持久化配置；旧环境变量仅作为尚未保存后台配置时的初始兼容来源。后台第一次保存后，数据库设置成为图片超分的权威配置。

普通用户的 `/api/v1/image-upscale/capabilities` 只返回 enabled、provider、倍率与尺寸限制，不返回任何密钥或密钥提示。

## 连接测试

新增管理员接口 `POST /api/admin/settings/image-upscale-test`。请求可以携带当前表单中的新凭据；服务端对空字段恢复已保存值，然后调用阿里云 STS `GetCallerIdentity` 验证身份。

连接测试不得：

- 上传图片；
- 调用图片超分；
- 创建 `image_upscale_jobs`；
- 返回 AccessKey、Secret 或 Security Token。

## 错误处理

- 未启用：画布能力返回 disabled，后台仍允许填写和测试配置。
- 密钥不完整：保存允许完成，但卡片显示“密钥待配置”；测试返回明确缺失项。
- STS Token 过期或鉴权失败：只返回安全的中文失败说明，不透传可能包含敏感字段的上游请求。
- 已保存配置读取失败：沿用现有后台设置错误提示，不回退到浏览器配置。

## 验收

1. 管理员能在私有设置看到图片超分卡片并保存开关与新凭据。
2. 刷新后密钥不回显，只显示已配置状态。
3. 留空再次保存不会清空已保存密钥；单独填写某一字段只覆盖该字段。
4. 测试连接不会产生超分任务或上传图片。
5. 禁用后画布超分弹窗提示服务端未配置/未启用；启用且凭据完整后可选择 2× / 4×。
6. 空图片节点的“图片高清”仍只是生图预设；真实超分仅对已有图片内容的节点显示。
