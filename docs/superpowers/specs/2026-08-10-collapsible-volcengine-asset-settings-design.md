# 火山素材审核配置折叠设计

## 背景

后台“系统设置 → 私有配置”中的火山素材审核配置包含说明、密钥状态和多项表单字段，长期展开会占据较多纵向空间，挤压下方模型渠道列表。

## 目标

- 火山素材审核配置支持手动展开和收起。
- 每次进入页面时默认收起，减少页面占用。
- 收起状态仍能看到关键运行状态。
- 折叠不影响表单保存和已有密钥保留逻辑。

## 交互设计

- 使用 Ant Design `Collapse` 替换当前外层 `Card`，保持现有管理后台主题和边框风格。
- 默认不设置活动面板，因此每次进入页面时保持收起。
- 标题栏显示“火山素材审核（唯一配置入口）”，并显示“已开启 / 已关闭”“Access Key 已保存 / 未填写”“Secret Key 已保存 / 未填写”三项摘要。
- 点击整行标题或展开图标切换状态，展开图标放在右侧。
- 展开后原有说明、密钥状态和全部表单字段保持原样，不改字段名称、校验、提示或保存数据。
- 不使用本地存储记忆展开状态。

## 数据与保存边界

- 折叠面板启用 `forceRender`，确保默认收起时内部表单字段仍注册在当前 Ant Design Form 中。
- 保存继续使用现有 `collectSettings`、`normalizeSettings` 和密钥合并逻辑。
- 不修改 API、后端设置模型或数据库。

## 验收

- 进入私有配置时火山素材审核区域默认收起，下方渠道操作和列表向上移动。
- 收起标题栏能看到启用状态以及 AK、SK 是否已保存。
- 点击标题可展开，再次点击可收起。
- 收起状态直接保存不会清空项目名称、地域、素材组、公网地址或已保存密钥。
- 展开后所有原字段和提示均可正常编辑。

## 非目标

- 不记忆用户上次展开状态。
- 不重排或精简火山素材审核表单字段。
- 不修改其他系统设置卡片或模型渠道表格。
