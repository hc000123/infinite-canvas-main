# 工作流素材安全去重设计

## 问题

同一个项目、同一集中的工作流素材可能同时保留旧语义编号（例如 `prop_red_paper_airplane`）和新稳定编号（例如 `PROP-001`）。素材库按记录计数，因此同名素材显示为两条；不同批次写入的类型元数据不一致时，同一概念还可能落入“文本”和素材名称两个分组。

## 目标

- 阻止旧编号和稳定编号继续写成两条素材记录。
- 收口已存在的重复工作流素材，使素材总数、搜索、分组和导出只出现一条。
- 保留已有图片、提示词、标签、版本和生成记录。
- 不删除仍可能被画布、分镜或历史工作流引用的旧素材 ID。
- 不合并不同项目、不同集数或只是碰巧同名的普通素材。

## 识别范围

只有同时满足以下条件的记录才属于同一去重候选组：

1. 都带有 `metadata.originalWorkflow`。
2. 项目 ID 和集数 ID 相同且非空。
3. 工作流素材名称规范化后相同；规范化仅去除首尾空白、合并连续空白并转为小写。
4. 候选组中至少有一条稳定逻辑编号，格式为 `CHAR-001`、`SCENE-001`、`PROP-001` 或 `COSTUME-001`。

不使用素材标题跨项目猜测，不处理普通手动素材，也不合并只有旧语义编号且无法确认稳定编号的记录。

## 规范记录选择

候选组只展示一条规范记录，按以下优先级选择：

1. 图片素材优先于文本素材。
2. 带稳定逻辑编号的记录优先于旧语义编号记录。
3. 优先保留更新时间较新的记录。
4. 最后使用素材 ID 保证选择结果稳定。

规范记录沿用原有素材 ID。其他记录不物理删除，而是在素材库查询结果中作为别名隐藏，避免已有引用立即失效。

## 信息合并

素材库生成规范视图时，为规范记录合并候选组信息：

- 标签去重合并。
- `previousVersions` 和 `generations` 按 ID 或内容键去重合并。
- 规范记录缺少备注、来源、封面或工作流提示词时，从别名记录补齐。
- 规范记录的 `originalWorkflow` 统一使用稳定逻辑编号，并记录同组旧素材 ID 和旧逻辑编号。
- 已有图片的二进制存储键、尺寸、媒体类型和当前版本不可被文本记录覆盖。

合并结果用于素材库展示、搜索、选择和导出。底层别名记录继续保留，以兼容旧引用。

## 后续写入防重复

资产设计写入时按以下顺序寻找目标记录：

1. 精确匹配 `projectId + episodeId + logicalAssetId`。
2. 在同一项目、同一集内匹配规范化后的工作流素材名称。

命中旧语义编号记录时，直接更新该记录的 `originalWorkflow` 为稳定编号，不再新增记录。不同项目或不同集数的同名素材不参与匹配。

## 素材库行为

- 素材总数、当前匹配数、分组数量和分页基于规范视图计算。
- 搜索结果只返回规范记录。
- 单项下载、导出选中和导出全部只处理规范记录。
- 详情和编辑操作作用于规范记录；本次不提供别名管理界面。
- 用户明确删除规范记录时同时删除同组别名，避免旧记录重新出现；这是自动去重不物理删除之外的唯一例外。

## 测试

1. 同项目同集、同名的 `PROP-001` 与旧语义编号合并为一个可见素材。
2. 图片记录优先，文本提示词、标签和历史信息得到保留。
3. 不同项目、不同集数的同名素材保持分离。
4. 两条普通手动同名素材保持分离。
5. 工作流再次写入稳定编号时更新旧记录，不新增素材。
6. 素材总数、搜索、导出选中和导出全部均不包含隐藏别名。

## 非目标

- 自动去重不物理删除历史别名记录；用户明确删除整个规范组时除外。
- 不重写画布、分镜、生产包或后端历史任务中的旧素材 ID。
- 不对所有普通素材做基于标题的自动去重。
