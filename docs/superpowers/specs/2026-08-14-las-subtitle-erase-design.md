# LAS 视频字幕擦除接入设计

## 目标

在画布已有内容的视频节点中增加独立“擦除字幕”能力，调用火山引擎北京地域 LAS `las_subtitle_erase / v1` 算子。原视频保持不变，处理结果作为右侧派生视频节点保存，并进入浏览器视频缓存和项目素材来源链。

本功能复用现有视频超分已经配置的 LAS API Key、火山 TOS AK/SK、异步任务、费用确认、结果下载和归档模式，但不要求用户同时执行视频超分或智能插帧。

## 方案选择

采用独立字幕擦除任务，不把擦除阶段塞进 `video_upscale_jobs`：

- 用户可以只擦字幕，不被迫支付视频超分费用。
- 擦除算子最高输出 1080P，独立任务能避免错误放在 2K 超分之后导致降分辨率。
- 独立状态、费用和失败重试更容易理解，也不会扩张当前已经包含超分与插帧的任务状态机。
- 暂不抽象通用后处理编排器；等字幕擦除、视频超分和插帧三条链稳定后再评估统一。

## 用户入口与交互

已有内容的视频节点提供“擦除字幕”动作，空视频节点不显示该动作。

点击后打开轻量确认弹窗，展示：

- 输入视频名称、分辨率、时长；
- 预计输出规则：MP4，最高 1080P；输入不超过 1080P 时保持原分辨率，超过时输出 1080P；
- 适用提示：优先用于竖屏白色硬字幕；复杂纹理背景可能出现局部模糊；
- 费用预估：`视频时长（分钟） × 0.4 元`；
- 云端处理与实际账单提示。

用户确认后：

1. 原节点保持不变。
2. 在右侧创建标题为“已擦字幕 · 原标题”的派生视频节点并连线。
3. 派生节点显示上传、LAS 处理、结果保存状态。
4. 成功结果立即缓存并归档；失败在同一节点重试。

弹窗不提供字幕位置、颜色、字体、遮罩范围或精细模式参数，因为当前算子没有这些正式参数。

## 服务端接口

新增独立接口：

- `GET /api/v1/video-subtitle-erase/capabilities`
- `POST /api/v1/video-subtitle-erase/jobs`
- `GET /api/v1/video-subtitle-erase/jobs/:id`
- `POST /api/v1/video-subtitle-erase/jobs/:id/retry`

创建接口使用 multipart 上传视频，并接收项目、画布、源节点和源资产引用。能力接口只返回是否可用、输入限制、输出限制、单价和计价规则版本，不返回密钥或 TOS 信息。

## 任务与数据模型

新增 `video_subtitle_erase_jobs`，保存：

- 用户、项目、画布、源节点、源资产引用；
- 本地输入路径、TOS 输入地址、输入大小、格式、宽高、时长；
- LAS Task ID、Request ID、任务状态、内部处理阶段、尝试次数；
- 输出 URL、本地持久化地址、输出大小、格式、宽高和时长；
- 预计计费分钟、预计费用、计价规则版本；
- 安全错误码、错误信息和时间字段。

公开状态沿用 `queued / uploading / processing / succeeded / failed`。内部阶段为：

```text
queued → uploading → subtitle_submitting → subtitle_processing → downloading → succeeded
```

画布节点新增独立 `subtitleErase` metadata，不复用 `videoUpscale` 字段，避免两种派生关系混淆。

## LAS 与 TOS 数据流

字幕擦除只接受公网 HTTP/HTTPS 输入，而现有视频超分上传后得到 `tos://` 地址。因此流程为：

1. 服务端把输入视频上传到现有北京 TOS 的 `video-subtitle-erase/input/` 前缀。
2. 提交 LAS 前临时生成 TOS 预签名 HTTPS GET 地址，不持久化带签名的完整 URL。
3. Submit 固定使用 `las_subtitle_erase / v1`，`client_token` 固定为本地 Job ID。
4. Poll 固定使用同一 operator 和已保存 Task ID。
5. LAS 完成后立即下载 24 小时有效的输出 URL，保存到本地公开结果目录。
6. 前端下载结果进入浏览器缓存，并按现有画布来源规则归档素材。

请求核心结构：

```json
{
  "operator_id": "las_subtitle_erase",
  "operator_version": "v1",
  "data": {
    "video_url": "https://signed-tos-input-url",
    "client_token": "video-subtitle-erase-job-id"
  }
}
```

## 配置

不新增第二套密钥。后台现有视频超分配置区调整为 LAS 视频处理配置，在不改变既有字段和超分行为的前提下增加“字幕擦除”启用开关：

- LAS API Key 继续复用 `private.videoUpscale.apiKey`；
- TOS AK/SK 继续复用火山素材配置；
- TOS bucket 从现有视频超分输出路径解析；
- 字幕擦除可用性单独返回，关闭字幕擦除不影响视频超分和插帧。

文件前缀由服务端自动创建，不要求用户手工建立目录。

## 费用

官方单价为 `0.4 元 / 输出分钟`：

```text
预计计费分钟 = 视频时长秒数 ÷ 60
预计费用 = 预计计费分钟 × 0.4
```

服务端使用 `ffprobe` 识别的时长生成并冻结费用快照。前端可使用节点视频元数据提前预览，但提交响应中的服务端快照才是任务记录真相。金额显示两位小数，并标注“预估金额，实际费用以火山引擎账单为准”。

## 重试、恢复与扣费安全

- LAS Submit 前完成格式、2K 输入上限、时长和配置校验。
- 首次提交和提交不确定后的安全重试始终使用同一个 `client_token`，利用上游幂等能力避免重复扣费。
- 已保存 Task ID 后只能 Poll 同一任务，不创建新的 LAS 任务。
- LAS 已完成但下载或本地保存失败时，只重新下载原结果。
- 服务重启后，根据持久化阶段恢复；不丢失 Task ID。
- 只有原视频确实丢失且尚未成功上传时，才要求用户重新创建任务。

## 输入、输出与安全

- 支持 `mp4 / flv / ts / avi / mov / wmv / mkv` 等文档列出的常规格式；浏览器入口沿用当前能够读取的视频格式。
- 输入最高 2K；超出时在任何 LAS 付费 Submit 前拒绝。
- 输出固定 MP4，最高 1080P。
- LAS 输出 URL 仅保留 24 小时，后台完成后必须立即转存。
- 结果下载沿用现有公网地址、重定向次数、响应大小和 MP4 内容校验，不访问私网地址。
- 不记录 Authorization、API Key、预签名查询参数或完整上游响应。

## 错误处理

- 服务未配置：入口禁用并引导管理员到 LAS 视频处理设置。
- 输入无效或超过 2K：本地校验失败，不调用 LAS。
- Submit 返回业务错误：保存安全错误码与 Request ID。
- Poll 返回 `FAILED`：显示安全中文说明并保留 Task ID。
- 结果超过 24 小时已失效：如果 LAS Task ID 仍可查询则重新 Poll 获取结果；无法恢复时要求新建任务并重新确认费用。
- 本地缓存或资产归档失败：画布结果仍保留，不重复提交 LAS。

## 测试与验收

按测试优先顺序实现：

1. Go 纯函数：费用、格式、2K 边界、状态归一化。
2. Provider：Submit operator、HTTPS 输入、稳定 client token、Poll 与结果解析。
3. 服务：保存输入、费用快照、阶段恢复、Task ID 复用、下载失败重试。
4. Handler / Repository：用户隔离、创建、查询和重试。
5. 前端：入口边界、费用确认、派生节点、刷新恢复、失败重试、缓存归档。
6. 回归：图片超分、视频超分、插帧和视频生成行为不变。

自动测试只调用假 Provider，不创建真实 LAS 付费任务。真实字幕擦除调用需要用户单独确认测试素材和费用；此前已经授权的真实视频超分与插帧验收仍按既定目标执行。

## 不在本阶段范围内

- 精细版字幕擦除、手动画框或局部修补；
- OCR 字幕导出、字幕翻译或重新压制字幕；
- 把字幕擦除强制串入视频超分与插帧；
- 通用视频后处理 DAG 或大规模画布重构；
- 自动覆盖原视频或自动替换资产主版本；
- 未经确认的真实付费字幕擦除测试。
