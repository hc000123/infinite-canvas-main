# 火山引擎视频超分设计

## 目标

在现有画布视频节点中增加云端视频超分能力，操作方式与图片超分一致。视频超分使用火山引擎北京地域 LAS Operator 服务；LAS API Key 独立保存，TOS 访问复用“火山素材审核”已保存的 AK/SK。原视频不被修改，结果作为右侧派生视频节点和新资产保存。

## 首期范围

- 只处理已有内容的视频节点，空视频节点不显示真实超分入口。
- 使用 LAS `Submit` / `Poll` 异步视频超分任务，算子固定为 `las_video_super_resolution / v1`。
- 默认策略为 `AIGC + Standard`，面向 AI 生成短剧视频。
- 默认保持原帧率、音频和 SDR，输出 H.264、MP4、8 bit。
- 低于 1080p 的输入默认提升到 1080p；1080p 输入允许选择 2K。
- 首期不开放 4K、Pro、智能插帧、HDR、音频降噪和自定义模板。
- 不修改 Seedance、即梦、星链或其他视频生成渠道逻辑。

## 后台配置

“后台设置 → 私有配置”新增“视频超分”折叠卡片：

- 独立启用开关；不依赖“火山素材审核”开关。
- 展示“复用火山素材审核 AK/SK”的配置状态，不重复提供密钥输入框。
- 配置火山视频点播空间名称。
- 固定展示默认策略 `AIGC + Standard` 和首期输出限制。
- 提供视频点播控制台跳转链接。
- 提供“测试连接”，只验证现有 AK/SK 对指定点播空间的只读访问能力，不上传视频、不创建画质增强任务。

如果 LAS API Key 或火山 TOS AK/SK 未配置，视频超分卡片显示对应配置待完成。后台设置读取和测试响应不得返回任何密钥明文。

## 画布交互

视频超分沿用图片超分的交互模式：

1. 已有内容的视频节点显示“超分”。
2. 点击后打开视频超分弹窗，展示源分辨率、目标分辨率、时长、预计输出规格和云端付费提示。
3. 用户选择可用目标规格并确认。
4. 原节点保持不变，在右侧创建派生视频节点并建立连线。
5. 派生节点显示上传、处理、下载和归档进度。
6. 失败后在同一服务端任务上重试，不重复创建画布节点。
7. 成功后写入浏览器视频缓存并归档到“我的素材”；资产归档失败不删除画布结果。

目标规格规则：

- 输入短边低于 1080p：提供 1080p。
- 输入达到 1080p 且低于 2K：提供 2K。
- 输入已达到 2K：首期不再提交超分，界面说明当前版本无需继续提升。
- 保持原始宽高比，不允许自由变形。

## 服务端架构

新增独立 `video_upscale_jobs` 任务模型、仓储、服务与路由，避免混入现有视频生成任务：

- 任务保存用户、项目、画布、源节点与源资产引用。
- 保存输入路径、输入规格、目标规格、任务状态、进度、尝试次数、火山 `RunId`、输出地址和安全错误信息。
- 不保存或返回 AK/SK。
- 服务端先把视频上传到同主账号北京地域 TOS 的 `video-upscale/input/`，再提交 LAS 任务，输出目录使用 `video-upscale/output/`。
- 后台 Worker 或状态查询轮询同一个 LAS Task ID，完成后读取 TOS 产物、下载并保存到公开结果目录。
- 服务重启时把中断中的本地任务恢复为可重试状态；已经提交火山 `RunId` 的任务优先继续查询，不重复创建付费上游任务。

能力接口只返回启用状态、服务商、允许的目标规格、输入限制和云端处理标记，不暴露空间名或密钥状态。

## 数据与安全

- TOS 读写复用 `private.volcengineAsset.accessKey` 和 `secretKey`；LAS Bearer Key 独立保存在 `private.videoUpscale.apiKey`。
- `private.videoUpscale` 保存启用状态、服务商、LAS API Key、TOS 输出目录和质量模式。
- 视频输入、VOD 媒资和增强结果会进入火山引擎基础设施，提交前必须明确提示。
- 结果下载继续拒绝私网地址、非 HTTP(S)、非法媒体类型和超限响应。
- 上游错误只保留火山错误码、`RequestId` / `RunId` 和安全中文说明，不保存签名、请求头或完整上游响应。

## 错误处理

- AK/SK 缺失：能力返回禁用，后台提示前往火山素材审核配置区。
- LAS Key、北京 TOS 输出目录缺失或无权访问：测试连接和提交均返回明确安全提示。
- 上传失败：任务标记 `upload_failed`，允许复用本地输入重试。
- 上游提交失败：保存安全错误码，不创建第二个派生节点。
- 上游处理中失败：保留 `RunId` 与安全原因，允许用户确认后重试。
- 下载或本地归档失败：如果上游任务已成功，只重新下载已有结果，不重复产生付费增强任务。

## 验收标准

1. 管理员无需重复填写 TOS AK/SK，只需启用视频超分并配置 LAS API Key 与 TOS 输出目录。
2. 测试连接不上传视频、不创建付费任务。
3. 有内容的视频节点可以按与图片超分一致的方式发起任务；空视频节点不显示真实超分入口。
4. 原视频节点不变，派生节点位于右侧并带连线。
5. 刷新页面能够恢复处理状态，失败重试不会重复创建节点。
6. 火山已成功而本地保存失败时，不重复提交付费任务。
7. 成功结果进入画布缓存和资产库，并保留来源、目标规格、`RunId`、耗时与错误诊断。
8. 现有图片超分、视频生成和火山素材加白流程保持不变。
