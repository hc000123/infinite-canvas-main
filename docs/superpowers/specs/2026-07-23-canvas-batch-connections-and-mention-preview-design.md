# 画布批量连线与 @ 素材预览恢复设计

## 目标

解决两个彼此独立的问题：

1. 多选画布节点后，从选中节点发起普通连线时，可一次把所有选中节点连接到新建节点或已有节点。
2. 恢复升级前已有的 `@` 素材能力，让所有带提示词输入区的节点重新显示上游素材候选，并把图片缩略图引用嵌入提示词文本。

`@` 素材只引用现有上游连接，不创建、删除或修改画布连线。

## 批量连线交互

### 触发条件

- 当前至少选中两个节点。
- 用户从选中集合中任意节点的普通右侧输出端发起连线。
- 拖到已有节点或画布空白处创建新节点时，均进入批量连接。
- 从未选中的节点发起连线时仍只连接该节点。

### 不进入批量的情况

- 从左侧输入端发起反向连接。
- 从首帧、尾帧等带专用 `handleId` 的接口发起连接。
- 其他需要唯一语义的专用连接。

这些情况继续沿用现有单节点行为，避免多张图片同时覆盖首帧或尾帧角色。

### 连接规则

- 创建目标节点前冻结本次连接的源节点集合，避免弹出新建菜单期间选择变化造成结果漂移。
- 每个源节点继续通过现有 `normalizeConnection` 校验方向和节点类型。
- 已存在的相同连线自动跳过。
- 单条不合法连接单独跳过，不阻止其他合法源节点连接。
- 至少创建一条有效连线即视为成功；全部无效或重复时显示明确提示。
- 新建目标节点只创建一次，完成后只选中新节点，保持当前创建节点交互。
- 批量连接不改变源节点位置、选择前的节点数据或其他连线。

## @ 素材预览恢复

### 支持范围

- 图片节点提示词。
- 视频节点提示词。
- 文本节点提示词。
- 图片 / 视频等生成配置节点的提示词。
- 后续其他节点只要复用统一提示词编辑器，即自动获得相同行为。

### 候选素材

- 只读取已经连接到当前节点的上游图片、视频和音频节点。
- 不展示当前画布中未连接的素材。
- 不因为选择 `@` 项而创建新连线。
- 候选顺序沿用当前上游生成输入顺序。

### 提示词内展示与持久化

- 所有提示词输入区复用现有 `CanvasPromptEditor` 和 `CanvasPromptDocument`，不再为图片、文本、配置节点维护另一套纯文本 `@` 实现。
- 图片引用在正文中显示缩略图、名称和序号；视频、音频沿用对应媒体标签。
- 引用内部保存真实画布节点 ID，序列化生成提示词时再映射为当前顺序的“图片 N / 视频 N / 音频 N”。
- 普通节点保存到 `promptDocument`；已经生成的图片或视频节点编辑时保存到 `promptDraftDocument`，不覆盖历史版本提示词。
- 展开编辑弹窗与节点内紧凑编辑器使用同一份结构化文档，打开、保存、取消均保持现有草稿语义。

### 失效处理

- 上游节点删除或对应连线断开后，已有 `@` 标签保留并显示失效状态。
- 失效引用存在时禁用生成，并提示用户删除标签或恢复连线。
- 不按标题或顺序自动改绑到其他素材。

## 代码边界

- `use-canvas-connections.ts` 负责冻结批量源、规划连接、过滤重复并提交状态。
- 批量连接规划提取为纯函数，输入节点、选择、发起接口、目标和已有连线，输出有效连接与跳过原因，便于自动测试。
- `canvas-nodes-layer.tsx` 继续负责为每个节点计算上游输入和 `@` 候选。
- `canvas-node-prompt-panel.tsx` 与 `canvas-config-node-panel.tsx` 统一接入 `CanvasPromptEditor`，页面装配层只传现有状态和动作。
- 不修改素材库数据结构，不新增全局状态，不把 `@` 引用转成画布连线。

## 测试与验收

自动测试覆盖：

- 多选普通输出端连接已有节点时生成多条有效连线。
- 多选后创建新节点只创建一个目标并连接所有合法源节点。
- 重复连接和非法配置节点连接被跳过。
- 未选中发起节点、输入端、首尾帧接口仍保持单连接。
- 图片、视频、文本和配置节点都获得上游媒体候选。
- 结构化 `@` 图片引用保存真实节点 ID并带缩略图 URL。
- 删除或断开上游后引用失效且阻止生成。
- 已生成媒体节点的 `@` 修改写入草稿文档，不污染历史版本。

页面验收重点：框选三张图片，从其中一张右侧拖到空白处创建视频节点，三张图应同时连入；打开新视频节点以及图片、文本、配置节点提示词，输入 `@` 都应看到各自已连接的上游素材和图片缩略图，选择素材后画布连线数量保持不变。

## 不做事项

- 不展示未连接的全画布素材。
- 不从素材库全局搜索候选。
- 不让 `@` 自动创建连线。
- 不批量写入首帧或尾帧专用接口。
- 不新增批量连线设置面板或复杂模式开关。
