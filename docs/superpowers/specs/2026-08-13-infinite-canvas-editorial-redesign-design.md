# 无限画布“电影制作案头”UI/UX 重设计

## 目标

将无限画布从通用 AI/SaaS 工具台重设计为克制、影像优先的电影制作案头。第一阶段只改造画布创作体验，解决视觉模板感、重复操作入口、常驻面板占位和任务状态过载，不改变生产数据与执行契约。

## 用户确认的方向

- 优先范围：无限画布创作。
- 视觉方向：电影制作案头。
- 工具方式：对象就地操作。
- 布局决定：不设置常驻右侧检查器。
- 品牌占位：空节点和首次生成无结果时使用“眨眼之间”Logo，不使用场记板。

## 现状问题

### 同质组件制造模板感

当前大量页面使用相似的半透明面板、圆角、阴影、Tag 和解释文案。画布内部也存在工具栏、节点条、检查器和多个浮层重复包装相同能力。视觉层级经常通过“再加一层容器”表达，内容本身被弱化。

### 同一动作重复出现

保存、导入、素材、整理和撤销等动作分散在顶部菜单、快捷区和底部工具栏。节点动作又同时存在于节点悬浮条与右侧检查器。用户难以判断哪个是主入口。

### 常驻检查器挤占画布

右侧检查器重复节点已有的图片、标题、描述和生成按钮，并持续减少可用画布宽度。它还需要在节点、镜头、生产包、助手和空画布上下文之间切换，缺少稳定对象边界。

### 技术状态压过创作对象

任务 ID、版本、费用、运行状态和追溯信息大量常驻，使画布像运行控制台。用户需要先理解系统结构，才能判断当前对象、下一动作和阻断原因。

## 设计原则

1. 内容优先：图片、视频、文本和节点关系是画布主视觉。
2. 一个动作一个主入口：其他入口只作为明确快捷方式或“更多”。
3. 对象就地：基础编辑和高频动作围绕当前节点出现。
4. 渐进披露：复杂设置与技术详情只在明确请求时临时打开。
5. 状态依附对象：生成、完成和失败反馈出现在对应节点上。
6. 完整归还画布：临时浮层关闭后不保留布局占位。
7. 可靠性不换皮：稳定引用、固定版本、确认和失败恢复规则保持不变。

## 画布布局

### 顶部栏

顶部只保留：

- 返回与画布菜单。
- 项目 / 分集 / 画布身份。
- 导入、素材、整理等少量全局动作。
- 保存状态或保存动作。

撤销、重做可以保留键盘快捷键，并在菜单或轻量快捷入口中提供，但不得与相同动作形成多个同权入口。

### 左侧创建栏

左侧栏只负责创建与放置：

- 选择。
- 文本。
- 图片。
- 视频。
- 音频。
- 其他节点类型通过单一扩展入口打开。

左侧栏不承担保存、整理、删除画布和资产管理。

### 节点就地操作

节点未选中时只显示内容、名称和必要参数。选中后，在节点外侧出现最多三个入口：

- 编辑。
- 当前节点最主要的推进动作，例如“生成预览”。
- 更多。

下载、归档、替换、审核、裁剪、超分、多角度、锁比例等低频动作进入“更多”或临时编辑面板。禁止再由常驻右栏重复展示同一操作。

### 临时编辑面板

本设计取消常驻检查器。复杂设置按以下规则打开：

- 桌面端优先使用紧凑 Popover、临时浮层或不占布局的悬浮面板。
- 内容较多时可使用 Drawer，但关闭后完整归还画布宽度。
- 移动端复杂编辑统一使用 Drawer。
- 同一时刻最多一个主任务面板和一个辅助浮层。
- Esc、点击遮罩或返回画布具有一致的关闭语义；关闭后焦点返回触发点。

节点标题、短提示词和少量基础参数优先在节点内直接编辑，避免重复表单。

### 运行摘要

全局仅保留一句低视觉重量摘要，例如：

- `2 个任务生成中`
- `2 个运行中 · 1 个需要处理`

点击后才展示队列、阻断原因与取消操作。任务 ID、账本、哈希、模型实参等进入技术详情，不在默认创作层常驻。

## 视觉系统

### 气质

使用克制的电影制作案头语言，不做复古胶片、仿旧纸张、霓虹 AI、豪华影棚或大面积装饰纹理。设计由素材、排版、对齐和节点关系建立识别度。

### 色彩

深色主题建议基线：

- 全局背景：`#171512`
- 画布背景：`#24211B`
- 节点 / 表面：`#2A261F`
- 细边框：暖灰中性色
- 剪辑标记色：`#DF593B`

标记色只用于选中边界、连接关系、焦点和唯一主推进动作，不用于大面积背景或所有按钮。成功、警告和失败使用语义色，但成功状态不长期占据画布。

浅色主题采用暖灰案头，而不是纯白 SaaS。深浅主题的布局、状态语义和操作位置保持一致。

### 排版

- 节点标题、镜号和重要创作对象可使用具有宋体气质的中文展示字体。
- 正文与操作使用清晰的中文黑体。
- 镜号、时长和少量技术编号使用等宽字体。
- 避免无业务价值的英文大写眉题进入正式产品界面。
- 字体方案必须支持中文覆盖、离线桌面包与可接受的资源体积；若不引入字体资源，则使用经过验证的本地字体栈。

### 表面与边界

- 节点圆角控制在 0–4px，临时浮层控制在 4–6px。
- 普通内容区最多两个稳定表面层级。
- 阴影只用于真正浮起的 Popover、Modal、Drawer 和拖动对象。
- 选中节点使用 1px 标记色边界，不使用蓝色发光和厚重阴影。
- 透明与背景模糊只用于临时工具，不再作为通用卡片风格。
- 媒体保持原始比例，标题与时长使用窄信息带承接。

## 品牌 Logo 占位规则

复用现有 `/logo.svg`，不新建另一套临时图标。

Logo 只用于：

- 空媒体节点。
- 等待上传的节点。
- 首次生成且尚无任何媒体结果的节点。
- 无缩略图时的轻量占位。

一旦节点存在真实媒体，就只显示真实素材或生成结果。已有媒体的重试、变体或失败继续保留旧媒体和引用快照，只叠加进度或错误，不退回 Logo。

Logo 不作为水印，不叠加到真实图片，不进入导出内容，也不作为素材回写。

## 节点状态

### 静止

显示内容、名称和必要参数，不显示永久成功 Tag 或技术元数据。

### 选中

使用单一细标记边界。就地操作出现在节点外部，不覆盖内容主体。

### 生成中

- 进度依附对应节点。
- 有旧媒体时保留旧媒体并叠加轻量进度。
- 首次生成无媒体时显示 Logo 占位和进度。
- 生成过程不得锁死整个画布，用户可以继续处理其他节点。

### 完成

- 显示新结果或新版本。
- 完成提示短暂出现后自动退场。
- 结果本身是主要反馈，不新增永久成功卡片。

### 失败

- 保留原媒体、原参数和引用快照。
- 节点持续显示发生了什么与允许的下一步。
- 技术错误和请求详情按需展开。
- 失败不得被误解释为生成结果丢失或资产归档失败。

## 交互与错误处理

- 选中、连接、移动和基础编辑即时反馈。
- 异步任务显示阶段与进度，但不阻断其他画布操作。
- 危险动作如删除画布、清空和付费批量生成继续确认。
- 付费动作、正式资产回写和版本确认边界不因 UI 简化而改变。
- Modal、Drawer 和临时浮层关闭后恢复原焦点和画布操作。
- 错误文案优先说明原因、影响对象和下一步；供应商原始错误放技术详情。

## 数据与架构边界

本次允许：

- 调整操作入口、显隐、排序和装配。
- 新增或收敛画布视觉 primitives。
- 统一临时面板互斥和关闭行为。
- 将重复检查器内容迁回节点或按需浮层。
- 调整任务状态的展示方式。

本次不改变：

- 节点与连线数据结构。
- `inputOrder` 和稳定媒体引用。
- 固定 `assetVersion` 与 `sourceAssetId` 语义。
- LocalForage 持久化结构。
- 普通缓存与正式资产回写规则。
- Workflow、Invocation、Artifact 和任务状态机。
- 上一镜尾帧只能作为普通 `continuity_reference` 的规则。
- 图片节点原始比例。

## 响应式与可访问性

- 桌面端临时编辑面板不得永久改变可用画布尺寸。
- 小屏复杂编辑使用 Drawer，关闭后回到完整画布。
- 390×844、768×1024、1280×900、1440×900 均不得出现关键操作不可达。
- 图标按钮必须有可理解名称，状态不能只靠颜色表达。
- 焦点顺序与视觉顺序一致；浮层关闭后返回触发点。
- 普通文本对比度至少 4.5:1，大文本与关键 UI 边界至少 3:1。
- 尊重减少动态效果设置；动画不是理解状态的必要条件。
- 选择、拖动、连接、删除、复制粘贴、撤销重做和 Esc 保持键盘可用。

## 验收标准

### 视觉

- 画布首屏以媒体、文本和节点关系为主，而不是面板、Tag 和解释文案。
- 默认画布没有常驻右侧检查器。
- 普通内容最多两个表面层级，无 Card 套 Card。
- 选中、运行、完成、失败可区分，但不依赖大面积色块或标签云。
- 空节点使用现有“眨眼之间”Logo，不出现场记板占位。

### 交互

- 每个动作在默认界面只有一个主入口。
- 节点未选中时不显示操作条；选中后最多显示编辑、主推进动作和更多。
- 用户可以在生成期间继续选择、移动和编辑其他节点。
- 临时编辑面板关闭后，节点与画布恢复原位置，不留下右侧空白。
- 错误状态能直接说明原因和下一步，技术详情按需查看。

### 回归

- 稳定 ID、删除/重排、`inputOrder` 和提示词媒体映射保持一致。
- 缓存成功与正式资产回写继续独立处理。
- 已有媒体的重试与变体不丢失历史引用和旧结果。
- 连续性尾帧仍是普通参考，不成为首帧。
- 付费确认、任务幂等、取消与失败恢复行为保持不变。
- 深浅主题和固定视口矩阵均通过人工视觉与交互验收。

## 分阶段建议

1. 画布视觉 primitives 与 token：节点、工具按钮、临时浮层、状态和 Logo 占位。
2. 顶部栏与左侧创建栏收敛，去除重复全局动作。
3. 节点就地操作与“更多”分层。
4. 移除常驻检查器，将基础编辑迁回节点、复杂编辑迁入临时面板。
5. 统一任务状态、错误和全局运行摘要。
6. 深浅主题、响应式、键盘与核心数据语义回归验收。

不建议一次性顺手改造项目、资产、工作台和后台；它们可以在本画布设计验证后复用视觉语言，但应分别进入后续规格。
