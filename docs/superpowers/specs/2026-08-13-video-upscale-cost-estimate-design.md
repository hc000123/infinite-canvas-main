# 视频超分输出选项与费用预估设计

## 目标

在现有画布“视频超分”弹窗内加入可理解、可验证的输出选项与费用预估，让用户在创建火山 LAS 付费任务前看见预计计费依据和金额。保持现有画布派生节点、任务轮询、结果归档和失败恢复逻辑不变。

本阶段实现 LAS 超分费用的准确预估，并为智能插帧展示能力边界。智能插帧渠道与单价尚未锁定时不得创建插帧任务，也不得把未知费用计入一个看似准确的总价。

## 用户界面

“视频超分”弹窗保留源规格、目标规格和时长信息，并新增两个区域。

### 输出选项

- 目标清晰度：沿用当前 `1080p / 2K` 可用性限制。
- 输出质量：`兼容 / 均衡 / 母版`，分别对应 LAS 的 `compatible / balanced / master`。
- 音频：保留原音频，默认开启。
- 帧率：
  - `保持原帧率`：当前唯一可提交选项。
  - `智能插帧 2×`：展示为“渠道待接入”，不可提交。
  - `智能插帧至 60fps`：展示为“渠道待接入”，不可提交。

插帧的处理顺序固定为“LAS 超分 → 智能插帧”。这样 LAS 仍按输入原帧率处理，不会因为先插帧而增加超分计费帧数。

### 费用卡片

弹窗实时显示：

- 原视频时长与帧率；
- 目标分辨率分类；
- LAS 分辨率系数；
- LAS 帧率系数；
- 折算计费时长；
- 超分预计费用；
- 插帧费用状态；
- 可计算时显示预计总费用。

提交按钮显示 `预计 ¥X.XX · 开始视频超分`。当源视频缺少可靠时长或帧率时，按钮仍可提交，但费用区域明确显示“暂无法预估”，不显示虚假金额。

## LAS 费用公式

单价固定为 `2.2 元 / 折算分钟`：

```text
折算分钟 = 视频时长（秒）÷ 60 × 分辨率系数 × 帧率系数
预计费用 = 2.2 × 折算分钟
```

分辨率系数按输出分辨率分类：

| 输出分辨率 | 系数 |
| --- | ---: |
| ≤720P | 1 |
| 720P＜≤1080P | 3 |
| 1080P＜≤1440P | 5 |
| ＞1440P | 11 |

帧率系数：

| 输出帧率 | 系数 |
| --- | ---: |
| ≤30fps | 1 |
| 30＜≤60fps | 2 |
| 60＜≤90fps | 3 |
| 90＜≤120fps | 4 |

费用计算使用 LAS 实际处理阶段的帧率。本阶段仅支持保持原帧率，因此使用源视频帧率。金额向上不强制取整，界面显示两位小数；计算内部保留完整精度。最终文案固定标注“预估金额，实际费用以火山引擎账单为准”。

示例：10 秒、24fps、1080p 输出：

```text
2.2 × (10 ÷ 60) × 3 × 1 = 1.10 元
```

## 数据与接口

### 能力接口

`GET /api/v1/video-upscale/capabilities` 增加公开计费与输出能力：

- LAS 单价；
- 分辨率与帧率折算规则版本；
- 支持的输出质量模式；
- 是否支持保留音频；
- 智能插帧状态 `unavailable`。

前端不自行硬编码单价。费用纯函数读取能力接口返回的规则并计算，便于价格调整和测试。

### 创建任务

`POST /api/v1/video-upscale/jobs` 增加：

- `outputQualityMode`；
- `preserveAudio`；
- `frameInterpolationMode`，本阶段只接受 `keep`。

服务端重新校验所有选项，不信任前端。任务表持久化本次选择和提交时的预计费用快照，任务响应返回：

- 输入帧率；
- 输出质量模式；
- 是否保留音频；
- 帧率模式；
- 预估折算分钟；
- 预估费用；
- 计价规则版本。

LAS Submit 使用任务快照中的 `output_quality_mode` 与 `preserve_audio`，避免管理员随后修改默认值影响已创建任务。

## 帧率识别

服务端 `ffprobe` 同时读取视频流的 `avg_frame_rate` 和 `r_frame_rate`：优先使用有效的 `avg_frame_rate`，否则使用 `r_frame_rate`。无法解析、为零或明显异常（大于 120fps）时不生成费用预估，并返回安全提示；不得猜测为 24 或 30fps。

画布已有视频节点可能没有帧率元数据。弹窗打开后可先显示“提交后由服务端精确校验”；若节点已有可靠帧率则立即给出预估。创建任务响应返回服务端精确值后，派生节点保存最终预估快照。

## 智能插帧边界

本阶段不调用普通 FFmpeg 补帧冒充 AI 插帧，也不创建真实插帧任务。界面展示两个禁用选项及说明：

- 火山插帧渠道和定价确认后才能启用；
- 插帧费用独立列示；
- 未知费用时不显示总价；
- 后续接入仍保持“先超分、后插帧”。

如果后续选择本地 RIFE，费用行显示“云端接口费 ¥0，消耗本地 GPU”，并另行设计并发、显存、超时与部署要求；不在本阶段范围内。

## 错误与安全

- 无有效时长或帧率：允许提交超分，但费用显示“暂无法预估”。
- 未知质量模式、关闭音频以外的非法布尔值、非 `keep` 插帧模式：服务端拒绝创建任务。
- 能力接口不可用：弹窗保留现有禁用逻辑，不采用前端兜底单价。
- 费用预估不是扣费上限，不承诺与最终账单完全一致。
- 测试费用计算时只使用纯函数、假 Provider 和本地媒体，不创建真实 LAS 或插帧任务。

## 测试

- Go 纯函数覆盖四档分辨率、四档帧率边界、10 秒 1080p 24fps 示例、无效帧率和小数时长。
- Go 服务测试覆盖任务选项校验、费用快照持久化、LAS Submit 使用任务快照。
- 前端测试覆盖费用明细、两位小数、未知费用、禁用插帧选项和带金额提交按钮。
- TypeScript、Go 相关包和 `git diff --check` 通过。
- 不进行新的真实付费测试；此前唯一一次 LAS 真实任务已经验证基础 Submit/Poll 与结果下载链路。

## 不在本阶段范围内

- 接入真实智能插帧供应商；
- 部署 RIFE 或其他本地 GPU 模型；
- 插帧定价；
- 将费用预估作为配额、扣款或账单系统；
- 修改画布节点派生、连线、轮询和资产归档主逻辑。
