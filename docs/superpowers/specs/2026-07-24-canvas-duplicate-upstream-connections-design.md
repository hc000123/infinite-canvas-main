# 画布节点复制继承上游连线设计

## 目标

减少重复搭建相同生成链路时的连线操作。复制节点后，新节点自动连接原节点的上游输入，同时作为一张新的生成草稿存在，不携带原节点已经生成的媒体结果和版本历史。

## 适用入口

- 节点右键菜单中的“复制”。
- `Ctrl / Cmd + C` 后使用 `Ctrl / Cmd + V` 粘贴。
- 单选和多选复制使用同一套数据规划逻辑，避免两个入口行为分叉。

## 连线规则

1. 只继承指向被复制节点的上游连线，不复制被复制节点指向下游的输出连线。
2. 保留原连线的 `fromHandle` 和 `toHandle`，确保普通输入、首帧、尾帧等专用语义不变。
3. 单节点复制时，上游源节点保持原 ID，新连线指向新节点 ID。
4. 多节点复制时：
   - 选区内部连线的源端和目标端都映射到对应的新节点。
   - 选区外部上游连线保留原源节点 ID，只把目标端映射到新节点。
   - 选区中节点连接到未选中下游节点的连线不复制。
5. 所有复制出的连线使用新 ID，不修改原连线。

## 节点数据规则

### 共同保留

- 节点类型、尺寸和与原节点相近但不重叠的位置。
- 当前有效提示词；如果存在尚未生成的提示词草稿，以草稿作为新节点正式提示词。
- 结构化 `promptDocument` 和其中绑定真实上游节点 ID 的 `@` 引用。
- 模型、画幅、分辨率、时长、质量、参考模式、首尾帧角色、输入顺序等生成参数。

### 图片和视频节点清理

复制出的图片、视频节点作为未生成的新节点，清理以下结果和运行态数据：

- 媒体内容、Blob / 缓存 / 远程地址、存储键、文件大小和媒体自然尺寸。
- `mediaVersions`、`currentMediaVersionId`、`pendingMediaVersion` 及提示词草稿字段。
- 任务 ID、任务状态、进度时间、错误、扣费回执和任务账本字段。
- 生成结果对应的素材归档身份、固定素材版本、火山素材审核身份。
- 旧结果的变体、连续镜头、派生来源和批量图片根子关系。

新节点状态回到 `idle`，首次生成从 v1 开始，不会继续叠加原节点版本。

### 文本、配置和音频节点

- 文本节点保留文本内容，因为它本身就是提示词输入。
- 生成配置节点保留提示词及全部生成参数，不携带任务结果状态。
- 音频节点没有媒体生成版本链，按普通素材节点保留内容；复制它作为其他选中节点的内部上游时，新连线连接到新音频节点。

## 实现边界

新增一个纯数据复制规划器，负责节点规范化、ID 映射和上游连线重建。右键复制与剪切板粘贴只负责传入当前节点、连线和目标位置，并应用规划结果，不各自维护字段清理规则。

本功能不复制上游节点本身；只有用户明确多选了上游节点时，上游节点才会一起复制。功能也不改变原节点、原连线、画布预设或媒体文件。

## 异常与安全

- 上游节点已经不存在的悬空连线不复制。
- 同一源、目标和接口组合只生成一条连线，避免旧数据中的重复连接继续放大。
- 新节点或新连线 ID 生成失败时不应用不完整结果。
- 复制不删除媒体文件，因此不会影响原节点的结果与版本。

## 测试范围

1. 单节点复制继承全部上游连线且不继承下游连线。
2. 首帧、尾帧和普通接口在复制后保持原接口字段。
3. 多选复制正确映射内部连线，并继承选区外部上游连线。
4. 图片和视频的新副本保留有效提示词、结构化引用和参数，但清空媒体、版本、任务、错误与素材身份。
5. 未生成的提示词草稿成为副本正式提示词。
6. 文本、配置和音频节点按各自规则复制。
7. 右键复制和快捷键复制粘贴应用相同规划结果。
8. 复制后原节点和原连线保持不变。
