# 画布节点已连接素材快速断线设计

## 目标

在节点的提示词编辑区域直接展示当前节点已经连接的上游媒体素材，让用户无需寻找画布连线即可确认引用来源，并通过单击 `×` 快速断开指定连线。

## 范围

- 覆盖图片、视频、文本和生成配置节点。
- 只展示直接连接到当前节点的上游图片、视频和音频，不展示间接上游或普通文本节点。
- 图片显示缩略图；视频和音频显示明确的媒体类型图标、序号和节点名称。
- 点击素材主体沿用现有预览动作；点击 `×` 只删除该素材到当前节点的对应连线，不删除素材节点，也不删除该素材与其他节点之间的连线。
- 首帧、尾帧等专用媒体连线同样展示并可断开，标签应说明其连接角色。
- 不新增确认弹窗。误操作通过画布现有撤销能力恢复。

## 交互设计

节点提示词编辑器上方增加一条紧凑的“已连接素材”区域。区域只在存在上游媒体素材时显示，使用横向换行布局，避免扩大节点面板的固定宽度。

每个素材项包含预览、类型序号、被截断的节点名称和一个独立的关闭按钮。关闭按钮使用 `aria-label="断开素材：<名称>"`，悬停提示“断开与当前节点的连线”。点击素材与点击关闭按钮必须互不冒泡，避免断线时同时打开预览。

视觉沿用 `canvasThemes`：低对比边框、轻量背景、4–6 像素间距和小尺寸圆角，不引入新的全局样式。关闭按钮只在悬停和键盘聚焦时增强对比，保持画布顶部和节点浮层的低视觉重量。

## 组件与数据流

新增一个画布私有展示组件，接收：

- 已连接媒体项：连接 ID、源节点 ID、目标节点 ID、类型、标签、标题、预览地址和专用连接角色。
- `onPreview(nodeId)`：调用现有素材预览动作。
- `onDisconnect(connectionId)`：调用现有 `deleteConnection`，确保删除、选中清理、历史记录和持久化继续走统一路径。

`CanvasNodesLayer` 根据当前节点 ID、画布节点和连接列表构建直接上游媒体项，并把同一份数据传给普通提示词面板和生成配置节点面板。纯数据转换放入 `canvas/utils/`，组件不自行遍历或修改全局画布状态。

断线后的数据流为：关闭按钮 → `deleteConnection(connectionId)` → connections 更新 → 上游素材项与 `@` 候选自动重新计算 → 节点面板移除该素材项。

## 提示词引用一致性

断线不会自动修改提示词文本或结构化提示词文档。若提示词仍包含该素材的 `@` 引用，现有校验会把它显示为失效引用并阻止生成，避免悄悄绑定到其他素材。用户可删除失效引用、重新连接原素材，或撤销断线。

## 边界与错误处理

- 同一源节点到同一目标节点若存在多个不同接口的连线，每个素材项按连接角色分别展示并只删除对应连接。
- 已删除或找不到源节点的连接不进入展示列表。
- 没有可预览地址时仍显示类型图标和节点名称，断线功能保持可用。
- 生成运行中允许断线；本次动作只影响后续输入状态，不取消已经提交的远程任务。

## 测试与验收

- 纯函数测试：只返回直接上游媒体；排除文本、间接上游和缺失节点；保留 connectionId 与首尾帧角色；顺序与当前连线输入顺序一致。
- 接线测试：普通提示词面板和生成配置面板都收到已连接素材及断线回调。
- 页面验收：连接图片、视频、音频后能看到预览条；点击预览打开对应素材；点击 `×` 后只有目标连线消失，素材节点与其他连线保留；提示词中的旧 `@` 标签变为失效提示；撤销可恢复连线。

## 不做事项

- 不在素材条中新增拖拽排序、批量断线或替换素材。
- 不自动删除提示词里的 `@` 标签。
- 不展示下游节点或间接依赖。
- 不修改现有连线数据结构和持久化格式。
