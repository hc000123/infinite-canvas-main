# 素材命名、收藏与视频详情设计

## 目标

统一画布生成素材的名称，让同一节点的不同版本在素材库中自然相邻；为全部素材增加收藏能力和独立筛选；简化视频详情并按原始比例完整播放。

## 命名规则

画布生成的图片和视频统一命名为：

`画布名称-节点001-v1`

- 画布名称取当前画布标题，不使用创意项目名或提示词。
- 各段之间统一使用半角连字符 `-`，连字符两侧不加空格，不再使用中点 `·`。
- 节点编号使用三位数字。节点首次归档时按当前画布节点顺序分配并写回节点 metadata；同一节点后续生成沿用该编号。
- 版本号优先取当前媒体版本，其次取生产视频版本，首次生成回退为 `v1`。
- 提示词仍保留在生成 metadata 中，可用于搜索和详情追溯，但不再进入素材标题。
- 旧素材不批量改名；新生成或再次生成的素材使用新规则。

## 收藏与筛选

- 在素材基础类型上增加可选 `favorite` 字段，继续由现有 localForage Zustand Store 持久化。
- 视频紧凑卡片和其他素材行均提供星标按钮；收藏只更新素材，不触发选择、打开详情或下载。
- 类型筛选行提供独立“收藏”筛选，可与类型、项目、文件夹、集数及高级筛选叠加。
- 仅收藏筛选不改变默认名称排序、分组和分页规则。

## 视频详情

- 普通视频详情移除顶部静音裁切缩略图和“内容”区域的第二个播放器。
- 标题与标签下只展示一个带 controls 的播放器。
- 播放器使用素材宽高数据设置自身 aspect-ratio，并同时受抽屉宽度与 `70vh` 高度约束：横屏优先利用宽度，竖屏优先利用高度。
- 播放器不再强制 `aspect-video` 或 `w-full`，从而避免竖屏视频被放进大面积 16:9 黑底。
- 图片、音频、文本和工作流素材详情保持原有结构。

## 架构边界

- 命名、节点编号与版本号计算放在画布纯工具中；生成 hooks 只传入真实画布标题并将分配的编号写回节点。
- 收藏字段放在素材 Store 类型中，筛选仍由 `asset-page-filters.ts` 处理。
- 收藏交互通过素材页现有 `updateAsset` 回调接线，卡片不直接读取全局 Store。
- 视频自适应尺寸由素材详情组件根据已有媒体尺寸计算，不新增全局 CSS。

## 验收

- 新生成图片和视频名称符合 `画布名称-节点001-v1`。
- 同一节点再次生成时节点编号不变、版本号递增。
- 任意素材可收藏/取消收藏，刷新后状态保留，收藏筛选可与其他筛选组合。
- 视频详情只出现一个播放器；720×1280 竖屏视频完整显示且无固定 16:9 外部黑边。
- 素材下载、分组、排序、分页、审核、画布归档与工作流引用保持可用。
