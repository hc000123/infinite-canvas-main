# 本集主画布自动创建剧本文本节点设计

## 背景

项目分集同时保存原剧本和优化稿：当 `sourceSummary` 存在时，`sourceSummary` 是原剧本，`summary` 是已确认的优化稿。当前首次创建本集主画布时会绑定分集并写入 `scriptSnapshot`，但画布中不会出现可见的剧本节点，且现有快照构造优先使用原剧本。

## 目标

首次创建本集主画布时，在默认视口的可见区域内自动创建一个标题为“本集剧本”的可编辑文本节点。节点正文优先使用当集优化稿；没有有效优化稿时，自动使用原剧本。

## 范围

- 仅在首次创建本集主画布时自动创建剧本文本节点。
- 重新进入已存在的主画布时，不新增、不替换、不覆盖现有节点。
- 新建子画布时不自动创建剧本文本节点。
- 不改变已有画布数据，不增加旧数据迁移或兼容补写。
- 不自动拆分剧本、生成分镜或触发任何 AI 请求。

## 数据选择

为画布构造剧本文本时使用以下固定优先级：

1. `sourceSummary` 和非空 `summary` 同时存在时，将 `summary` 视为已确认优化稿。
2. 没有有效优化稿时，使用 `sourceSummary` 或 `summary` 中的现有原剧本。
3. 原剧本回退沿用现有分集标题、场次和摘要组装规则；优化稿保持完整正文，不重复拼接原场次。

画布的 `scriptSnapshot` 与自动创建的文本节点使用同一份文本，保证可见内容和后续画布流程读取的剧本一致。

## 创建流程

1. 用户在项目分集页点击“创建画布”。
2. 页面根据当集数据选择优化稿或原剧本，构造画布分集上下文。
3. 主画布不存在时，画布 store 创建主画布，并在初始 `nodes` 中写入一个现有类型的文本节点。
4. 节点使用固定的默认起始坐标，确保在初始视口内可见；标题为“本集剧本”，状态为可用，正文为选定的完整剧本。
5. 主画布已存在时，保持现有节点集合不变，只执行现有的进入画布流程。

## 实现边界

- 剧本选择保持为纯函数，由分集上下文工具负责，不在页面中重复写字段判断。
- 初始剧本节点使用项目现有的 `CanvasNodeType.Text` 和文本节点元数据结构，不新增节点类型。
- 节点初始化只放在主画布的“不存在则创建”分支，从结构上避免重复创建。
- 不修改子画布创建逻辑。

## 异常与边界情况

- 优化稿为空白时视为不存在，回退到原剧本。
- 分集剧本文本最终为空时，不创建空文本节点；主画布仍按现有逻辑创建。
- 后续重新优化剧本不自动覆盖已创建的画布节点，避免丢失用户在画布中的编辑。

## 测试与验收

自动化测试覆盖：

- 分集同时有原剧本和优化稿时，画布剧本文本选择优化稿。
- 分集没有优化稿时，选择原剧本。
- 首次创建主画布时，初始节点中有且仅有一个“本集剧本”文本节点。
- 已存在主画布时再次进入，不新增或覆盖剧本节点。
- 新建子画布时，不自动创建剧本节点。

人工验收路径：

1. 为某一集保存优化稿，首次创建本集主画布，确认画布中央出现“本集剧本”文本节点，内容为优化稿。
2. 为只有原剧本的分集首次创建主画布，确认节点内容为原剧本。
3. 退出后重新进入已创建的主画布，确认不重复添加节点，也不覆盖已编辑内容。
4. 在该主画布下创建子画布，确认子画布为空画布。
