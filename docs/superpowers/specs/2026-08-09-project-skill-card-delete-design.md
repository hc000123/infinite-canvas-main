# 项目 Skill 卡片删除入口设计

## 目标

在项目 Skill 管理页的左侧注册表中，让制作人员可以直接发现并删除可编辑的 Project Skill，不需要先选中 Skill 再滚动到右侧生命周期区域。

## 交互设计

- Project Skill 卡片右上角常驻显示删除图标，图标使用项目已有的危险操作样式。
- System Skill 不显示删除入口；项目页只读展示 System Skill，其生命周期由管理员后台负责。
- 点击删除图标时阻止卡片选中事件，并弹出二次确认。
- 确认文案显示 Skill 名称，并说明只有从未发布、没有引用的 Skill 才能删除。
- 删除请求期间显示加载状态，防止重复提交。
- 删除成功后刷新 Skill 列表，清除已删除 Skill 的版本选中状态，并让现有列表规则自动选中下一个可用 Skill。
- 右侧“生命周期”中的删除入口保留，与卡片入口共用同一删除行为。

## 权限与错误处理

- 前端仅向 `ownerType === "project"` 的 Skill 提供删除操作。
- 不改变现有后端删除规则和 API。
- 如果 Skill 已发布、已被引用或后端拒绝删除，保留当前选中状态并显示后端错误信息。

## 测试与验收

- Project Skill 卡片显示删除操作，System Skill 卡片不显示。
- 点击删除不触发卡片选中。
- 未经确认不发送删除请求。
- 确认后调用目标 Skill ID 的现有删除 API。
- 删除成功后列表刷新且不再引用已删除 Skill；删除失败时界面状态不丢失。

## 范围外

- 不增加 System Skill 的项目侧删除权限。
- 不增加强制删除、批量删除或数据库清理逻辑。
- 不修改版本归档、停用或引用关系规则。
