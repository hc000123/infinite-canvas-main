# UI 布局可靠性设计

## 目标

在不改变现有深色主题、业务流程与数据结构的前提下，修复桌面端主要页面的内容不可达、横向裁切、画布面板遮挡和长列表低效问题。首阶段以 1280×900 与 1440×900 为验收尺寸。

## 设计原则

- 保留现有画布顶部工具栏、Ant Design 表单和后台双栏的视觉语言。
- 每个普通页面只保留一个主滚动容器；工作台和编辑器允许列表、详情独立滚动。
- 宽表在内容区内横向滚动，固定首要识别列和操作列，不让表格撑破页面。
- 画布视图计算使用真实可用尺寸；面板展开后节点、底部工具条和视图中心仍处于安全区内。
- 空状态只保留一个主操作；长说明在列表中截断，完整内容放在详情区。

## P0 范围

### 生产总控

`/agent` 使用自身主滚动容器，工作台高度不再被外层 `100dvh` 与 `overflow-hidden` 截断。选中分集后，页面可以滚动到工作台底部。

### 任务运维

任务表格继续保留全部运维字段，但在卡片内部提供横向滚动。时间和操作列固定，窄桌面仍能查看详情、刷新和返还操作。

### 画布列表与工作区

- 项目画布页头在宽度不足时换行，绑定旧画布与新建画布按钮不会离开视口。
- `重置视图` 与 `整理画布` 使用可见节点和真实画布尺寸计算适配视图。
- 画布右侧面板在中等桌面宽度降低占用；底部工具条根据面板状态预留右侧安全区。
- 新插入或整理后的节点必须能通过一次重置视图全部看到。

### Skill 管理

项目 Skill 与后台 Skill 统一为列表区独立滚动、详情区保持可见。列表卡片说明最多两行，版本轨道进入左侧滚动区，避免页面向下滚动后右侧空白。

## P1/P2 补充范围

- 项目详情只把“分集 / 项目画布”作为二级视图；生产总控保留为主操作，Skill 与项目缓存进入更多菜单。
- 项目、画布等空状态不重复页头已有的主操作，降低无数据页面的高度和视觉重量。
- 新建项目与画布预设表单增加模型字段宽度，设置页保存栏吸顶，资产工具栏在 1280px 内容区主动换行。
- 提示词封面使用明暗棋盘底板兼容透明和深色素材；数据中心四张统计卡统一网格，登录审批空状态收紧。

## 非目标

- 不重做品牌、颜色、字体或业务文案。
- 不调整后端接口、权限、Skill 生命周期或画布持久化结构。
- 不在本阶段重构所有管理后台页面。

## 验收标准

- 1280×900 与 1440×900 下没有关键按钮位于视口外。
- `/agent` 可以滚动到工作台末尾。
- 任务运维表格可横向滚动，时间与操作列始终可用。
- 展开画布右侧面板时，节点操作和底部工具条不被面板覆盖。
- 整理画布或重置视图后，全部可见节点处于画布安全区内。
- Skill 长列表滚动时，选中详情仍留在视口中。
- 项目页头、资产工具栏和主要后台操作在 1280×900 与 1440×900 下无横向溢出；设置页滚动后保存操作仍可见。
