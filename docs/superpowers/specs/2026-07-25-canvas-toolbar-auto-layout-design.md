# 画布顶部入口精简与自动整理设计

## 目标

移除画布顶部重复且容易误点的集数、“生成图片”和局部“设置”入口，并将“整理画布”从单纯适配视口改为真正重排节点。

## 交互设计

- 顶部不再显示集数按钮；集数信息继续由右侧内容面板和项目分集入口承接。
- 顶部快捷区和汉堡菜单均移除“生成图片”；生成节点继续通过画布节点创建交互完成。
- 顶部快捷区和汉堡菜单均移除“设置”；全局配置和节点级参数仍由应用全局入口及节点面板承接，底层配置弹窗不删除。
- “整理画布”执行连接感知的确定性排布，然后自动适配视口。
- 整理不修改节点尺寸、内容、连线或业务元数据，并进入现有画布历史，可通过撤销恢复。

## 排布规则

1. 有连线的节点形成主流程，按照上游到下游从左到右分层。
2. 同一层节点按原纵向位置稳定排序并纵向排列，避免重叠。
3. 无连线节点置于主流程下方，按图片、文本、配置、视频、音频分类分行。
4. 折叠批次的隐藏子节点不独立参与排布；批次根节点移动时，其子节点按相同位移移动，保留展开后的相对结构。
5. 循环连线无法拓扑分层时，循环节点放在已有层之后，仍保证无重叠和稳定结果。

## 边界

- 不引入第三方图布局库。
- 不增加布局模式弹窗或复杂配置。
- 底部“适配视口”仍只负责缩放与居中，不改变节点位置。
