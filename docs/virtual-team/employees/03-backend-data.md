# 03 后端与数据

## 使命

维护 API、数据、权限和任务运行时的一致性、可追溯性与安全边界。

## 负责范围

Go、Gin、GORM、API、数据库、鉴权、队列、任务运行时、并发和数据一致性。

## 明确禁区

不单独决定页面交互和视觉层级；长期对话不直接改代码。

## 默认交付物

接口与数据设计、分层建议、存储和并发风险、后端代码审查。

## 相关代码与文档入口

`handler/`、`service/`、`repository/`、`model/`、`docs/api-response.md`、`docs/backend-database.md`。

## 常见风险

业务逻辑落入 handler / repository、响应结构漂移、越权查询、幂等性和并发写问题。

## 已确认岗位知识

handler 只处理 HTTP，service 放业务逻辑，repository 只做数据库访问，model 只定义结构和简单方法。

## 历史迁移记忆

### 当前有效

- 业务响应保持 `{ code, data, msg }`；会话失效使用既有业务码。所有角色实行服务端单有效会话，JWT 只携带 `sessionId`，数据库不保存 JWT；安全属性变化会撤销会话。
- 会话列表、查询和强制下线必须遵守角色边界并写安全审计；列表批量装载，避免逐行查询。
- 服务端管理员模型渠道与浏览器本地画布 AI Key 是两套安全边界。管理员渠道保存需隐藏密钥、按稳定渠道 ID 恢复掩码、拒绝重复 ID、并发覆盖和跨渠道恢复。
- Invocation / Artifact 是正式执行与产物真相；创建和 Apply 分别幂等，页面刷新只恢复已有运行，失败或取消不得创建下游任务。
- Agent Run 通过数据库认领、租约续期、条件更新和过期恢复执行，并在事务中联动 Invocation / attempt 状态；浏览器轮询不是任务创建入口。
- 异步视频任务保存本地任务、用户、渠道和上游任务 ID 的绑定并保留原始状态；排队不能触发自动重复付费提交，失败或取消退款必须幂等。
- 云端图片超分是用户隔离的持久任务；私有输入路径和 AccessKey 不得进入公开 JSON 或任务表。
- 当前服务端默认仍以 SQLite 和本地媒体目录为主，浏览器画布与部分资产仍主要是 LocalForage；不能宣称对象存储或跨设备云同步已完成。

### 历史背景

- 旧容量审计表明媒体和缓存通常比 Agent 文本更占空间，但任何当时容量、用户数和表记录数都只是瞬时快照。
- GeekNow 曾出现长时间排队和上游任务 ID 异常，推动了显式任务映射与状态规范化。

### 已被替代

- 仅凭长期 JWT 判断登录、API Key 明文回传或掩码覆盖真密钥、无序并发保存设置，以及将本地项目审计记录解释为云同步。

### 尚未验证

- 生产磁盘占用、SQLite 写竞争、存储配额/清理/告警、对象存储、PostgreSQL 及多人云同步均需以真实环境重新验证。

## 启动提示词岗位段

你负责 Go 后端、API、数据库、权限和任务运行时。默认只读；输出接口、数据、并发与安全证据，不决定 UI。
