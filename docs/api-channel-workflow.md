# API 渠道与 Agent 绑定规则

本文档约束后台 API 渠道、Agent 配置、工作流阶段和生成任务之间的绑定关系。目标是让火山企业 API、即梦 CLI、星链云和中转 API 都进入同一个可审计、可预检、可扣费、可隔离的执行体系，避免前端散落 Key、避免一个全局模型覆盖所有 Agent。

## 总原则

- 所有 API Key、Base URL、模型、费用、协议、预检和启停状态都由后台系统设置维护。
- 私有渠道负责注册协议、凭据、模型和能力；公开配置只负责开放范围、三类默认模型与计费，前端不再维护第二套协议判断。
- 同一个模型 ID 可以绑定多个同协议渠道，但不能跨协议复用；跨协议场景必须使用不同的公开模型 ID。
- 前端和普通用户不能看到完整 Key，只能看到渠道名、模型名、协议、是否已配置、Key 尾号和预检结果。
- 后台 API 渠道是统一资源池，但每个 Agent、工作流阶段、图片任务、视频任务和 CLI 任务都必须能单独选择渠道和模型。
- 模型解析优先级固定为：节点 / Agent 单独设置 -> 项目级默认设置 -> 后台全局默认设置 -> 不可用则阻断；每一层都必须同时满足已开放和能力匹配。
- 节点只持久化模型 ID 和生成参数，实际协议在请求前根据后台模型目录解析；旧 `provider` 字段不能覆盖协议映射。
- 不允许自动切换到更贵渠道；只有用户或管理员明确允许 fallback，且 fallback 候选已经配置费用和预检通过时，才能切换。
- Agent、图片、视频、CLI 任务只产出草案、任务结果或映射预览；写入资产、分镜、视频生产包、画布或触发高费用批量任务前必须人工确认。
- 任何失败都不能污染正式业务数据。失败结果只能进入任务记录、错误诊断和可重试状态。

## 渠道类型

### 火山企业 API

用途：

- Seedance / Ark 视频生成。
- 视频任务查询、同步结果、下载或代理下载。
- 素材加白、素材审核状态刷新。
- 企业视频 API 非扣费预检。

渠道要求：

- 协议标识使用 `volcengine-ark`。
- 必须配置 `baseUrl`、`apiKey`、`models`、`endpointId` 或 `endpointMappings`。
- 视频模型必须能解析到具体 Endpoint / EP。
- 预检只能验证鉴权、模型和 Endpoint 映射，不创建视频任务，不扣费。

前端可见信息：

- 渠道名、模型名、协议、Base URL 安全展示、Endpoint / EP、Key 是否配置、Key 尾号、预检状态。

前端不可见信息：

- 完整 API Key、AK/SK、内部请求头、后台完整错误栈。

### 即梦 CLI

用途：

- 本地或服务器受控视频生成。
- 本地或服务器工作流执行。
- 需要 CLI 登录态、输出目录、日志和停止任务能力的任务。

当前已接入受控 `dreamina` 视频五模式：`text2video`、`image2video`、`frames2video`、`multiframe2video` 与 `multimodal2video`。预检 CLI / 登录态 / 输出目录，提交、查询和下载均由后端白名单参数执行；图片、视频和音频参考必须通过前端 multipart 上传为受控临时文件，JSON 或 URL 参考暂不直接交给 CLI。显式模型支持集包含 Seedance 2.5；多帧命令不传模型但必须传 720p / 1080p 清晰度。CLI 队列、停止任务、日志回传和通用工作流 Worker 仍按本节完整目标继续规划。

渠道要求：

- 即梦 CLI 不能作为裸命令由网页直接触发。
- 上云后必须作为后端 Worker 或受控任务执行，不能让前端传任意命令。
- 必须固定可执行文件路径、工作目录、输出目录、允许的参数白名单、超时时间、并发限制和用户隔离目录。
- CLI 任务必须支持日志回传、状态查询、停止任务、输出文件归档和失败诊断。

预检必须检查：

- CLI 是否安装。
- CLI 版本是否满足要求。
- 登录态是否有效。
- 输出目录是否可写。
- Worker 是否可接收任务。
- 停止任务能力是否可用。
- 日志回传是否可用。

前端可见信息：

- CLI 渠道名、版本、登录态是否有效、Worker 状态、输出目录是否可用、最近预检结果。

前端不可见信息：

- 服务器绝对敏感路径、登录凭据、环境变量、完整命令行、内部 token。

### 中转 API

用途：

- 语言模型。
- 图片模型。
- OpenAI 兼容文本 / 图片模型来源。
- 低成本或备用模型来源。

渠道要求：

- 协议标识建议使用 `openai` 或后续扩展为 `openai-compatible`。
- 必须配置 `baseUrl`、`apiKey`、`models`、费用和启用状态。
- 文本模型、图片模型需要分能力声明，不能只靠模型名猜用途。
- 预检只能做模型列表、轻量鉴权或最小非生成检查；如果供应商不支持非扣费预检，后台必须标记为“无法非扣费预检”，运行前按高风险处理。

前端可见信息：

- 渠道名、模型名、协议、能力、Key 是否配置、Key 尾号、费用、预检状态。

前端不可见信息：

- 完整 Key、代理内部域名、供应商私有错误细节。

## 后台渠道资源池

后台系统设置中的渠道是统一资源池。现有 `private.channels` 可继续作为基础结构，但需要逐步补齐以下语义：

```json
{
  "id": "channel_xxx",
  "name": "火山 Seedance 企业通道",
  "protocol": "volcengine-ark",
  "capabilities": ["video", "video_query", "asset_review", "preflight"],
  "environment": "prod",
  "baseUrl": "https://...",
  "apiKey": "hidden",
  "models": ["doubao-seedance-2-0"],
  "endpointId": "ep-xxx",
  "endpointMappings": [{ "model": "doubao-seedance-2-0", "endpointId": "ep-xxx" }],
  "enabled": true,
  "weight": 1,
  "costs": [{ "model": "doubao-seedance-2-0", "credits": 100 }],
  "preflight": {
    "status": "passed",
    "checkedAt": "",
    "message": ""
  }
}
```

字段规则：

- `id` 是绑定 Agent 和任务时的稳定引用，不使用显示名称做主键。
- `protocol` 决定后端适配器：`openai`、`volcengine-ark`、`jimeng-cli`。
- `capabilities` 决定可用于哪些任务：`text`、`image`、`video`、`video_query`、`asset_review`、`preflight`、`cli_workflow`。
- `environment` 用于区分 `dev`、`test`、`prod`。测试环境不能默认命中正式高价视频 API。
- `costs` 必须能覆盖模型和任务类型。未配置费用的高费用任务默认阻断。
- `enabled=false` 的渠道不能被任何 Agent 或任务命中，即使被旧配置引用也必须阻断。

## Agent 绑定配置

每个 Agent 配置中应逐步补齐以下执行字段：

```json
{
  "channelId": "channel_text_low_cost",
  "model": "gpt-5.5",
  "temperature": 0.4,
  "maxOutputTokens": 12000,
  "reasoningLevel": "高",
  "estimatedCredits": 3,
  "allowFallback": false,
  "fallbackChannelIds": [],
  "allowBatch": true,
  "timeoutSeconds": 300,
  "concurrencyLimit": 1
}
```

字段规则：

- `channelId` 指定后台渠道。为空时进入项目级默认。
- `model` 指定模型。为空时读取对应层级默认模型。
- `temperature`、`maxOutputTokens`、`reasoningLevel` 是 Agent 自己的运行参数，不被全局文本模型覆盖。
- `estimatedCredits` 用于运行前展示费用预估；实际扣费以命中的渠道和模型为准。
- `allowFallback=false` 时，只要指定渠道或模型不可用，就直接阻断。
- `allowFallback=true` 时，只能在 `fallbackChannelIds` 或项目 / 后台明确配置的同能力候选中选择。
- `allowBatch=false` 时，该 Agent 不允许被批量运行按钮调用。
- `timeoutSeconds` 到期后任务进入 `failed` 或 `timeout`，不能继续写入正式数据。
- `concurrencyLimit` 用于限制同用户、同项目或同 Agent 的并发。

## 项目级默认设置

项目可定义默认执行策略，用来避免每个 Agent 都重复配置：

```json
{
  "textDefault": {
    "channelId": "channel_text_default",
    "model": "gpt-5.5"
  },
  "imageDefault": {
    "channelId": "channel_image_default",
    "model": "gpt-image-2"
  },
  "videoDefault": {
    "channelId": "channel_seedance",
    "model": "doubao-seedance-2-0"
  },
  "cliDefault": {
    "channelId": "channel_jimeng_cli"
  },
  "allowFallback": false,
  "batchConfirmThresholdCredits": 100
}
```

项目级默认只能补空值，不能覆盖 Agent 已明确选择的渠道和模型。

## 后台全局默认设置

后台全局默认是最后兜底：

- 默认文本模型。
- 默认图片模型。
- 默认视频模型。
- 默认 CLI 渠道。
- 默认费用规则。
- 默认环境策略。
- 默认批量确认阈值。

如果后台全局默认也不可用，任务必须阻断，并给出缺少渠道、缺少模型、缺少 Key、预检失败或费用未配置等明确原因。

## 执行决策树

创建任务前按以下顺序解析：

1. 读取任务类型：Agent / image / video / cli。
2. 读取 Agent 单独设置或当前生成任务设置。
3. 如果缺少渠道或模型，读取项目级默认。
4. 如果仍缺少，读取后台全局默认。
5. 使用统一模型目录确认模型已公开且能力匹配；不满足则继续下一个默认层级，全部无效时阻断。
6. 根据模型协议映射筛选渠道，不读取节点旧 `provider`，也不按模型名称猜测协议。
7. 检查渠道是否启用、能力是否匹配、模型是否属于渠道允许模型。
8. 检查环境是否允许，例如测试环境不能默认使用 production 视频通道。
9. 检查预检状态是否通过或是否需要重新预检。
10. 计算费用预估。
11. 检查用户额度。
12. 如果是高费用或批量任务，要求二次确认。
13. 创建任务记录。
14. 后端 Worker 或服务端适配器执行。
15. 保存原始输出、结构化结果、错误和耗时。
16. 等待用户确认后再写入正式业务数据。

## Fallback 规则

默认禁止 fallback。

允许 fallback 时必须满足：

- 用户或管理员明确打开 `allowFallback`。
- 候选渠道能力相同。
- 候选渠道环境允许当前任务。
- 候选渠道预检通过。
- 候选模型费用不高于原模型，或用户已确认可能增加费用。
- 任务记录必须写清原始目标、实际命中渠道和 fallback 原因。

禁止 fallback 的情况：

- 从测试渠道自动切到正式渠道。
- 从低价文本模型自动切到高价推理模型。
- 从文本生成自动切到视频生成。
- 从 API 任务自动切到 CLI 任务。
- 预检失败后偷偷换渠道继续扣费。

## 预检规则

预检必须是非扣费或明确标记为非生成检查。预检失败时不能创建正式任务。

文本模型预检：

- 检查渠道启用状态。
- 检查 Key 是否配置。
- 检查 Base URL 是否可访问。
- 检查模型是否存在或可被渠道接受。
- 如果支持非扣费模型列表，优先用模型列表。
- 如果只能通过最小请求验证，必须在后台标记其可能产生费用，并不自动执行。

图片模型预检：

- 检查渠道、Key、Base URL 和模型。
- 检查输出格式、尺寸限制和费用配置。
- 不自动生成测试图片。

火山企业 API 预检：

- 检查 Ark 鉴权。
- 检查模型到 Endpoint / EP 的映射。
- 检查视频任务查询能力。
- 检查素材加白配置，包括 AK/SK、ProjectName、Region、AssetGroupID。
- 不创建视频任务，不提交素材审核。

即梦 CLI 预检：

- 检查 CLI 安装路径和版本。
- 检查登录态。
- 检查 Worker 心跳。
- 检查用户隔离目录和输出目录权限。
- 检查日志回传、停止任务和输出归档能力。
- 不执行真实生成。

## 费用与确认

费用规则：

- 每个模型和任务类型都必须能算出预估费用。
- Agent 文本任务按模型、推理强度、max output tokens 或后台配置估算。
- 图片任务按模型、尺寸、张数、质量估算。
- 视频任务按模型、时长、清晰度、数量和参考素材估算。
- CLI 任务可以按任务类型、预计时长或固定额度估算。

确认规则：

- 单次低费用 Agent 可直接运行，但仍需记录费用。
- 批量 Agent 运行前显示总费用预估。
- 批量图片生成前显示总费用预估。
- 批量视频生成、高费用 API、production 环境视频 API 必须二次确认。
- 额度不足时阻断，不创建上游任务。
- 上游创建失败或任务取消时按幂等规则返还额度。

## 任务记录

每次 Agent / 图片 / 视频 / CLI 执行都必须记录：

- 任务 ID。
- 用户 ID、项目 ID、集数 ID。
- 任务类型和来源入口。
- 目标渠道、目标模型。
- 实际命中渠道、实际模型。
- fallback 是否发生及原因。
- 输入快照，包括剧本、阶段产物、提示词、参考资产、生成参数。
- 原始请求和脱敏后的请求 JSON。
- 原始输出。
- 结构化结果。
- 审核结果。
- 映射预览。
- 状态：created、queued、running、needs_review、succeeded、failed、cancelled、timeout、approved、applied。
- 错误码和错误信息。
- 开始时间、结束时间、耗时。
- 预估费用、实际消耗额度、返还额度。
- 写入了哪些资产、分镜、视频生产包、画布节点或素材版本。

记录要求：

- API Key、Authorization、token、secret、base64、blob URL 和文件内容必须脱敏。
- 任务失败时只更新任务记录，不写正式业务数据。
- 任务成功但未确认时只进入草案或映射预览，不写正式业务数据。
- 同编号视频再次生成时写新版本，不覆盖旧素材。

## 失败处理

Key 错误：

- 状态为 failed。
- 显示渠道名、模型名、Key 尾号和预检建议。
- 不写正式数据。
- 已扣额度按失败返还。

模型不存在：

- 状态为 failed。
- 显示模型名和命中的渠道。
- 不自动切换模型，除非允许 fallback。

额度不足：

- 创建上游任务前阻断。
- 不产生上游请求。

任务超时：

- 状态为 timeout 或 failed。
- 保留上游任务 ID。
- 如果上游可能仍在执行，允许后续同步结果。

CLI 卡住：

- Worker 标记 stalled。
- 支持停止任务。
- 日志回传到任务记录。
- 输出目录未确认前不导入正式素材。

上游返回格式错误：

- 保存原始输出。
- 结构化结果为空或标记解析失败。
- 进入 needs_fix 或 failed。
- 不写正式业务数据。

## 即梦 CLI 上云边界

即梦 CLI 上云时必须满足：

- 网页只能创建受控任务，不能传任意命令。
- 后端 Worker 根据任务类型选择固定命令模板。
- 每个用户或项目使用隔离工作目录。
- 输出文件先进入临时任务目录，校验后再进入对象存储或素材库。
- 日志按任务 ID 持久化，前端只读日志片段。
- 支持停止任务和超时清理。
- 支持并发限制，避免一个用户占满服务器。
- 支持环境隔离，开发 / 测试任务不能误用正式输出目录和正式高价账号。

## 环境隔离

环境类型：

- `development`：本地开发，可使用 mock、低价模型或本地 CLI。
- `test`：测试验收，默认禁止命中 production 高价视频渠道。
- `production`：正式生产，可命中企业视频 API，但高费用任务必须二次确认。

规则：

- 渠道必须标记环境。
- 项目可绑定允许的环境。
- 任务创建时检查当前部署环境、项目环境和渠道环境是否匹配。
- 测试环境如需使用正式渠道，必须管理员显式临时授权，并在任务记录中标记。
- 文档、日志和页面提示必须明确当前环境，避免测试误扣正式额度。

## 页面与入口规则

后台系统设置：

- 管理渠道资源池。
- 管理 Key、Base URL、模型、Endpoint、费用、环境、预检。
- 显示安全诊断，不显示完整 Key。

Agent 中心：

- 配置 Agent 的渠道、模型、参数、费用、fallback、批量、超时、并发。
- 可从项目级默认或后台默认继承。
- 不保存完整 Key。

视频工作流：

- 阶段启动读取 Agent 绑定。
- 每个阶段展示实际命中的渠道、模型、费用和预检结果。
- 阶段结果进入草案 / 映射预览，确认后写入资产、分镜或视频生产包。

视频生产台：

- 每条视频提示词使用自己的生成设置。
- 批量生成前汇总各条费用。
- 生成后按提示词编号保存视频版本。

我的素材：

- 展示生成来源、任务、渠道、模型、参数和加白状态。
- 素材加白只走后端火山企业 API。

## 当前实现与后续落地

当前已有基础：

- 后端系统设置维护模型渠道和私有 Key。
- 前端 AI 请求默认走 `/api/v1/*` 后端代理。
- 视频生成已有 `ai_tasks` 账本、火山 Ark 预检和额度记录。
- Agent 配置和 Agent Run 已开始迁移到后端持久化。

后续需要补齐：

- 渠道稳定 `id`、能力、环境、预检状态和费用矩阵。
