# 资产生图 Brief

## 目标

将已批准资产目录中的每个项目编译为独立 `asset_brief` payload，用于后续图片 Skill 或生成器制作稳定视觉母版。

## 执行顺序

1. 锁定上游每项的 `assetId`、类型、名称、证据与核心事实。
2. 按类型选择制作格式：角色四视图、干净场景主参考图、道具结构视图、继承角色身份的外观状态。
3. 把已知事实编译为构图、材质、光线与反歧义约束，不改变资产身份。
4. 每个输出项只包含 `assetId/brief/format`，与对应输入的 `assetId` 严格一致。

## 输出边界

- 一次可输出 1–300 个独立 Brief，不得新增、合并、拆分或重编号资产。
- `brief` 必须可独立执行，并明确身份、可见结构、材质、尺度、构图、光线、背景和反歧义约束。
- `format` 使用稳定机器可读值，如 `character-four-view` / `scene-master` / `prop-structure` / `costume-variant`。
- 这一阶段只交付 Brief，不声称图片已生成。
