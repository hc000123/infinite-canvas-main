# 视频提示词包编译规则

## 四段成品

每个 `prompt` 按以下顺序组织：

1. **场景：** 交代地点、时间、空间布局、氛围、光线方向和画面质感。
2. **声音：** 写环境底噪、与动作同步的音效、原台词与语气。
3. **画面内容：** 使用如 `0-2秒`、`2-5秒` 的连续区间覆盖整镜，每段写主体动作、可执行表演、一个主运镜和段落终点。
4. **限制：** 只写当前镜头真正的失败风险，优先是身份、空间、服装、持物、光向、动作节奏和无意切镜。

## 时间轴与可跟随性

时间段必须从 0 开始，相邻区间首尾相接，最后结束于分镜时长。不跳秒，不重叠，不用“随后”取代时间预算。简单镜头只保留一个主动作与一个主运镜。

## Artifact 引用

- `inputArtifactRefs` 中的 `artifactId/contentHash` 必须原样来自冻结输入，不得重算、截断或格式化。
- 使用绑定名区分分镜包、资产目录与资产变体；没有使用的参考不得虚构引用。
- 不从图片重新推导剧情，不用一张参考图覆盖另一张的专属职责。

## 上一镜尾帧的强制边界

上一镜尾帧只能作为 `continuity_reference` 普通参考图，用于理解剧情从上一画面之后继续。继承场景、角色身份、服装、持物、伤势、光线、材质和画风状态，但必须让新动作在此后发生。严禁将它标记或提交为首帧，严禁要求第一帧复刻该图。
