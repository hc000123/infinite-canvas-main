# 单镜头编译规则

## 四段成品

`prompt` 按以下顺序组织：

1. **场景：** 交代地点、时间、空间布局、氛围、光线方向和画面质感，只保留对当前镜头可执行的部分。
2. **声音：** 写环境底噪、与动作同步的音效、原台词与语气。不为空镜增加旁白，不擅自改台词。
3. **画面内容：** 使用如 `0-2秒`、`2-5秒`的连续区间覆盖整镜。每段写主体动作、可执行表演、一个主运镜和段落终点。
4. **限制：** 只写当前镜头真正的失败风险，优先是身份、空间、服装、持物、光向、动作节奏和无意切镜。

## 时间轴与可跟随性

时间段必须从 0 开始，相邻区间首尾相接，最后结束于 `durationSeconds`。不跳秒，不重叠，不用“随后”取代时间预算。简单镜头只保留一个主动作与一个主运镜；密集动作可写一条因果相连的动作链，但不叠加互不相干的动作。动作要有速度质感和停止状态，避免运动退化为静帧。

## 参考图绑定

- 每个 `@图N` 都先说明它提供的角色身份、外观马甲、场景空间、道具结构、调度或剧情连续性，再用一次引用绑定。
- `referenceEvidence[].imageRef` 与成品引用一一对应；`observations` 写图中真实可见信息；`appliedTo` 写该信息用于哪个资产 ID 或镜头职责。
- 不从图片重新推导剧情，不用一张参考图覆盖另一张的专属职责。

## 上一镜尾帧的强制边界

上一镜尾帧只能作为 `continuity_reference` 普通参考图，用于理解剧情从上一画面之后继续。继承场景、角色身份、服装、持物、伤势、光线、材质和画风状态，但必须让新动作在此后发生。严禁把它标记或提交为首帧，严禁要求第一帧复刻该图，严禁据此重新诠释画风、材质或角色设定。

## 哈希约束

`promptInputHash` 是当前剧本、分镜和参考版本的身份锁。必须原样回写，不重算、不截断、不格式化。
