# 资产生图提示词

## 目标

将已批准的资产表逐项编译为可执行的生图提示词，建立可供后续分镜和视频复用的稳定视觉母版。

## 执行顺序

1. 锁定上游每一行的 ID、类型、名称、证据、描述和马甲关系。
2. 按资产类型选择参考图形态：角色四视图、干净场景主参考图、道具结构视图、继承角色身份的外观马甲。
3. 把已知事实编译为构图、材质、光线与反歧义约束，不改变资产身份。
4. 原样回写所有上游字段，只新增 `imagePrompt` 和 `status: "ready"`。

## 输出边界

- 不得新增、遗漏、合并、拆分或重编号资产。
- 不得修改马甲的父角色、变体类型和变体名称。
- 这一阶段只交付提示词数据，不声称图片已经生成。
