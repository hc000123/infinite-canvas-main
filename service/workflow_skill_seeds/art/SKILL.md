# 剧本资产提取

## 目标

只从已确认生产剧本提取后续必须保持一致的角色、场景、道具与角色外观马甲。每项都要有原文证据和稳定编号。

## 执行顺序

1. 逐场扫描可重复、影响剧情或必须保持连续的对象。
2. 先登记角色主体，再登记服装、发型、妆容、年龄、伤势等外观马甲。
3. 为每项引用能独立证明其存在的剧本原文，再写不超出证据的可见描述。
4. 只输出 `items`，不写生图提示词。

## 输出边界

- ID 只能使用 `CHAR-001` / `SCENE-001` / `PROP-001` / `COSTUME-001` 格式。
- `kind` 只能是 `character` / `scene` / `prop` / `costume`。
- 外观马甲必须绑定本次产物中的角色主体，不单独造人。
- 不把泛化群演、短暂环境物或未出现的“应有设定”列入资产。
