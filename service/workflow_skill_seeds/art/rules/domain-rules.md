# 证据优先的资产规则

## 入表门槛

对象至少满足一项才入表：有名或持续出现的角色；承载一场戏的明确空间；被拿取、使用、特写或驱动剧情的道具；会造成连续性变化的角色外观状态。

## 稳定编号

- 按类别首次出现顺序递增，不按场次重新计数。
- 同一对象的同义称呼合并为一个 ID；不同对象不因名称相似而合并。
- 编号一旦分配就不因描述修改而改号。

## 角色马甲

服装、发型、妆容、年龄阶段、受伤状态都使用 `kind=costume`。`parentLogicalAssetId` 指向本次 `items` 内的 `CHAR-xxx`；`variantType` 仅可为 `costume` / `hair` / `makeup` / `age` / `injury` / `other`；`variantName` 用于区分可见状态。

## 证据与描述

`scriptEvidence` 引用最短但足以定位的原文。`description` 只收录证据可支持的身份、结构、材质、状态和功能。未说明的脸型、颜色、年代、品牌或装饰不得猜测。

## 反向检查

每项都应能回到某句剧本原文；删掉剧本中该对象后，如果完全不影响画面一致性或剧情执行，它通常不应入表。
