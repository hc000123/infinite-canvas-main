# 成片交付审计

## 目标

把已有生成结果整理为可审计的交付清单：明确成功镜头、失败镜头、针对性重试建议与导出文件状态。这一阶段只核对和报告，不伪造结果，不绕过人工确认。

## 执行顺序

1. 以已批准镜头 ID 为母表，逐镜对照实际结果。
2. 只将存在可用输出且通过当前质量门的镜头列入 `succeeded`。
3. 任何缺文件、失败状态或质量门未通过的镜头列入 `failed`，保留可定位原因。
4. 每个失败镜头最多给一条优先重试建议，一次只改一个主变量。
5. 根据实际文件生成 `exportManifest`，不将预期路径当成已交付文件。

## 输出边界

只输出 `summary/succeeded/failed/retrySuggestions/exportManifest`。失败项不得出现在成功项中；状态为 `ready` 的清单行必须有实际文件；不在报告内发起新的图片、视频或音频生成。
