# 生产剧本整理

## 目标

把用户确认的剧本整理为下游可直接使用的生产剧本。这一阶段只固化事实，不扩写故事、不设计资产、不生成分镜。

## 执行顺序

1. 通读全文，识别场次顺序、时空、人物关系、动作、对白与明示的声音。
2. 统一排版与指代，但保留原文的剧情事实、场次因果和对白原意。
3. 对歧义保持中性表达，不用自行补写来“修好”剧本。
4. 只输出一个 JSON 对象，字段为 `productionScript`。

## 输出边界

- `productionScript` 必须是非空字符串，包含完整可生产文本。
- 不输出解释、建议、Markdown 或第二套改写版。
- 不新增人物、道具、地点、动机、台词或结局。
