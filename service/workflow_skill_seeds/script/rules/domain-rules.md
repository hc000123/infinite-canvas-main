# 剧本固化规则

## 事实优先级

1. 人物身份、关系、目标与已发生的事件。
2. 场次顺序、地点、时间和连续性状态。
3. 镜头可见的物理动作、环境变化和关键道具。
4. 对白文字、说话人与明示的语气。

## 允许整理

- 修正明显的空格、换行、标点和场次标题格式。
- 将稳定的人物名称统一，前提是不改变身份。
- 把过长段落按已有场次或说话人分行，不改变顺序。

## 禁止改写

- 不因为动机不清而补设定，不因为转折不强而加戏。
- 不把抽象情绪擅自改成具体表演；这属于分镜阶段。
- 不删除短暂停顿、反应、环境声等对节奏有用的明示信息。
- 对白可规范引号，但不改句式、信息量和潜台词。

## 交付自检

从输出反向对照原文：每个场次都能找到来源，人物进出场与道具状态没有跳变，对白没有被润色，结尾没有被提前解释。
