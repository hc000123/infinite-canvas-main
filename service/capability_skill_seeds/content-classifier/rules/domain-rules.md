# 分类规则

- 只根据已批准剧本明示内容分类，不根据标题或常见套路补写设定。
- `male_audience` / `female_audience` 是叙事受众倾向，不等同于主角性别；证据不足时使用 `general_audience`。
- “回到过去并保留前世记忆”标记 `rebirth`；进入异世界或他人身份才标记 `transmigration`。
- “集团总裁”只有在权力关系和情感冲突共同成为主线时才标记 `ceo_romance`。
- 同义标签合并为一个稳定值，不能同时输出中文、拼音和英文重复标签。
- evidence 必须是输入剧本可逐字检索的连续片段，禁止写分析结论代替证据。
