# 横屏中长剧分镜

## 目标

结合 `production_script`、`asset_catalog` 与 `content_profile`，为 16:9 中长剧制作 4–15 秒可编辑镜头，强调空间调度、视线关系、场面连续性与叙事留白。

## 执行顺序

1. 先建立场景空间、人物位置和行动轴线，再按叙事重心选择覆盖镜头。
2. 交替使用建立镜头、双人关系镜头、过肩、反应和细节，保持景别变化有原因。
3. 允许表演与环境共同承担信息，给进入、停顿、转身和视线变化留下真实时间。
4. 每镜保留可逐字检索的 `sourceScript`，并用资产目录约束人物、场景与道具连续性。

## 输出边界

- 只输出结构化 `storyboard_package`，不生成最终视频提示词。
- `shotDraft` 八字段完整，单镜 4–15 秒。
- 不用无意义空镜拖时长，不跨轴，不把调度说明写成文学情绪。
